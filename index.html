IMU 传感器模拟

这组滑块决定「喂给算法的数据有多脏」。真实 IMU 的缺陷可归为三类：零偏（恒定的系统性偏差）、 噪声（随机抖动）、动态误差（运动本身对测量的污染）——每个滑块对应其中一项。 左上「IMU 原始数据」chip 显示的正是经过这些污染后的实际输出，可随时对照。

陀螺仪零偏 0 – 5 °/s

是什么陀螺仪输出角速度时自带的恒定偏差——即使机体完全静止，它也一直报告一个小角速度。

起什么作用姿态完全由陀螺仪积分得到，这个偏差每一步都被积进姿态，是漂移的主要来源（推导见数学原理·陀螺仪积分方程）。

改了会怎样调大后红色曲线（纯陀螺仪积分）以更快的速度线性飞走； Mahony 的积分项会慢慢把它估计出来并抵消（把 Ki 也调到 0 可验证：只靠 Kp 时零偏永远消不掉）。

陀螺仪噪声 0 – 2 °/s

是什么陀螺仪输出的随机白噪声，叠加在真实角速度上，每帧独立。

起什么作用被积分后变成姿态上的随机游走；同时压缩了算法可用的信息量。

改了会怎样曲线整体变毛糙；融合算法会被迫调低修正增益来滤掉它（这正是 β/α 参数存在的意义）—— 噪声大时把 β 或 α 调小，曲线立刻变平滑，但跟踪变慢，两者权衡。

加速度计噪声 0 – 1 m/s²

是什么加速度计输出的随机噪声，叠加在「重力 + 运动加速度」上。

起什么作用污染算法的「观测」：加速度计是唯一的横滚/俯仰参照，噪声大时观测本身不可信。

改了会怎样玻璃盒里品红箭头（实测重力方向）开始抖动；互补/融合算法输出随之抖， 需要调小 α 或 β 来抑制。纯陀螺仪积分完全不受影响——它不看加速度计。

机动线加速度 0 – 5 m/s²

是什么机动时机体加减速产生的运动加速度。加速度计分不清重力和它——这就是「比力」的含义。

起什么作用人为制造加速度计失效场景：输出 = 重力 + 这个分量，方向随机动变化。

改了会怎样调大后剧烈机动时品红箭头明显甩偏、面板出现红色「受扰」提示、 融合算法误差曲线抬头。好算法靠「幅度门控」（测到的总量明显偏离 g 时降权）自救——幅度不同现象不同，可对比观察。

电机振动 0 – 1

是什么机架高频抖动的简化模型：叠加在陀螺仪和加速度计上的高频小幅振荡。

起什么作用模拟真实无人机最大的工程烦恼——振动频段的能量会被积分进姿态，也会污染观测。

改了会怎样曲线出现细密毛刺；500 Hz 解算完全在采样频带内，无法靠快滤掉—— 只能靠调低融合增益（β/α）或降采样，这正是真实飞控要装减震垫的原因。

解算算法

五种算法同时接收同一份脏数据、各自解算，误差曲线同图对比。思路一览：

  • 纯陀螺仪积分——只用陀螺仪，不修正。动态完美、恒定漂移，是「不融合会怎样」的对照组（红线）。
  • 互补滤波——陀螺仪积分（高通）与加速度计角度（低通）按比例混合，欧拉角域实现，最直观。
  • Mahony——把重力方向误差经 P/I 反馈注入陀螺仪积分，飞控最常用；多一个积分项能消零偏。
  • Madgwick——把姿态估计写成优化问题，沿目标函数梯度下降，单参数 β，计算量小。
  • 卡尔曼滤波——同时估计「姿态有多不准」（协方差 P），按预测/观测方差自动加权修正，还能顺带估出陀螺仪零偏。
启用磁力计（MARG） 开关

是什么让三个融合算法额外使用磁力计数据——MARG = 磁力计 + 角速度 + 重力。

起什么作用加速度计绕重力轴怎么转读数都不变，所以定不了偏航；磁场的水平分量提供「磁北」参照， 经倾斜补偿后专门约束偏航通道。

改了会怎样有零偏时（默认 1°/s），关掉它偏航误差持续累积、琥珀色机头箭头慢慢离开罗盘方向； 勾上后偏航被磁场拉住回正。若同时把「磁干扰强度」拉大，偏航会被拉偏一个稳定误差——磁场被污染了。

Mahony Kp 0.05 – 5

是什么比例增益：误差多大，修正角速度就给多大（e = Kp·误差）。

起什么作用决定「把姿态拉回观测」的速度。Kp 越大，加速度计的发言权越大，收敛越快。

改了会怎样调大：误差收敛明显变快，但噪声也被放大，曲线变抖；调小：平滑但慢。 极端调到 0.05：几乎只剩陀螺仪积分，慢慢漂移；调到 5：跟得很紧但毛刺明显。

Mahony Ki 0 – 0.5

是什么积分增益：误差的累积量也参与修正。

起什么作用稳态时比例项趋于零，积分项恰好收敛到「陀螺仪零偏的补偿值」—— 这是 Mahony 能自动消零偏的机制（数学上：e 的直流分量被积分器吸收）。

改了会怎样设 0：有零偏时收敛后仍留一个稳定小偏差；调大：消零偏更快，但过大会振荡超调。 配合「陀螺仪零偏」滑块做实验：Ki=0.05 时约几秒收敛到零误差，Ki=0 则永远差一点。

Madgwick β 0.01 – 1

是什么梯度下降的步长：每秒沿「预测重力与实测重力之差」的负梯度方向走多远。

起什么作用一个参数同时扮演 Mahony 里 Kp 的角色：权衡跟随速度与噪声抑制。

改了会怎样与 Kp 现象一致：大 β 快而抖、小 β 慢而稳。默认 0.1 是论文推荐的折中。 注意 β 没有积分项——对恒定零偏会留下小幅稳态误差，这是它和 Mahony 的实际差别。

互补 α 0.05 – 5

是什么互补滤波的混合权重：角度修正量 = α × 加速度计角度误差。

起什么作用α 大等于低通截止频率高——更信加速度计；等价于频域里陀螺仪高通、加速度计低通的交叉点。

改了会怎样行为与 Kp 类似但更粗糙：它工作在欧拉角域、没有积分项，且在俯仰接近 ±90° 时 误差定义本身会退化（欧拉角的固有缺陷）。调到极端值对比 Mahony，能看出「为什么飞控不用朴素互补」。

卡尔曼 Q（过程噪声） 0.01 – 2 °/s

是什么预测模型的不确定度——「陀螺仪积分这一步有多不可信」，进入协方差传播 Q·dt。

起什么作用与观测噪声 R 一起决定卡尔曼增益：Q 大 → 估计方差涨得快 → 每帧更信观测。

改了会怎样调大：跟随变快但毛刺明显；调小：平滑但机动中跟不上。设成与「陀螺仪噪声」滑块一致（0.2）即与真实噪声水平匹配。

卡尔曼 R（观测噪声） 0.005 – 1 g

是什么观测的不确定度——「加速度计/磁力计方向有多不可信」（单位 g，重力归一化后）。

起什么作用R 大 → 增益变小 → 更信预测；它同时参与 40° 新息门控的置信度评估。

改了会怎样拉到最大：几乎退化成纯积分（误差慢慢漂移）；调小：收敛极快但抖。配合「剧烈机动」剧本体验「机动中自动偏信陀螺仪」的自适应行为。

数学原理

总览：从「传感器原始数据」到「无人机姿态」

开跑前还有一个问题——第一帧的姿态是谁给的？本装置 t = 0 时假设机体水平放置 （q = [1,0,0,0]）；真实系统这一步叫「初始对准」（静置用加速度计/磁力计对出初始姿态， 见工程实践备忘），之后才交给下面的循环接管。

先建立一个画面：无人机悬停在空中，它自己并不知道自己是什么姿势。机体内部没有任何魔法， 只有三个小传感器各报告一条数据。姿态解算要回答的问题是—— 只凭这三条数据，如何推断出「我现在头朝哪、身子歪了多少」？

三个传感器各自能感知什么？用身体的直觉来类比：

  • 陀螺仪——像你的内耳：闭上眼睛转圈，你能感觉到「正在转、转多快」，但转完后说不清总共转了多少度（靠积累印象，会累积误差）。
  • 加速度计——像手机的重力感应或手里的水平仪：静止时能准确指出「哪边是下」，可一动起来（加减速）就乱报。
  • 磁力计——就是电子指南针：总知道磁北在哪，但怕电机与金属的磁场干扰。

三者各有所长也各有所短，谁也不能单独完成任务。解算算法每 2 毫秒（500 Hz）做一轮四步循环，把它们拧成一股：

数学工具箱：整个推导只需要这五件

全部是高中以内的数学。读后面任何一节卡住时，回到这里。

① 向量：既有方向又有长度的箭头

传感器输出的三个数 (x, y, z) 就是一个向量的三个分量。例如加速度计读 (0, 0, 9.8) 表示 「一根指向机体系 z 轴、长度 9.8 的箭头」。长度记作 ‖v‖ = √(x²+y²+z²)。 归一化 = 向量除以自己的长度，得到只表示方向、长度恰为 1 的箭头——姿态解算里几乎只用「方向」，所以到处都在归一化。

② 点积：量「两个箭头有多同向」

a·b = ax·bx + ay·by + az·bz = ‖a‖·‖b‖·cos θ。两箭头同向时取最大值，垂直时为 0，反向时为负。 用途：反查夹角（cos θ = 点积 ÷ 长度乘积）；判断两个四元数是否同指一个旋转（点积为正还是为负）。

③ 叉积：由两个箭头造出「垂直于它们」的第三个

a×b 的方向由右手定则给出——右手四指从 a 弯向 b，拇指所指就是 a×b 的方向；大小 = ‖a‖·‖b‖·sin θ。 这是整个解算最重要的工具，两个关键用途： 方向——「把箭头 g 拧到箭头 a」应该绕哪根轴转（叉积方向就是那根轴）； 大小——小角度时 sin θ ≈ θ，误差越大叉积越长。融合算法的「误差信号」就是一个叉积。

④ 导数与数值积分：变化率与「下一刻 = 现在 + 变化率 × dt」

q 读作「q 的导数」，含义是 q 每秒变化多少。计算机不会连续微积分，只能一小步一小步走： q(t + dt) ≈ q(t) + q(t)·dt，本装置 dt = 2 毫秒（500 Hz）。步子足够小时，这条折线与真实曲线几乎重合—— 这就是「数值积分」，也是陀螺仪数据变成姿态的全过程。

⑤ 小角度近似与旋转矩阵

θ 很小时（弧度制）：sin θ ≈ θ，cos θ ≈ 1。它把三角函数运算变成简单乘加——后文所有「≈」都来自这里。 旋转矩阵 R 是一张 3×3 的换算表：世界系向量左乘 R 得到它在机体系的投影，左乘 RT 则反向。 矩阵只是「查表」，推导时我会把它拆成一行行分量写出来。

为什么恰好是四个数

欧拉角三个数就够描述姿态了，四元数却用四个——多出来的这个数不是浪费， 而是把弯曲的旋转空间摊平所付的「摊平费」。这件事从最简单的平面旋转就能看清楚。

台阶一：平面转角——角度会跳变，圆不会

平面里转一个角度 θ，看起来一个数就够。但它有个隐患：θ 本身在 ±180° 处断开—— 转 +179° 与转 −179° 明明只差 2°，数值上却差 358°；两个角度相加也不封闭 （170°+170° = 340°，等价的应是 −20°）。解决办法是把角度「裹」到圆上： 用 (cosθ, sinθ) 两个数表示——这就是复数。复数乘法 = 转角相加， 处处连续、永不跳变。1 个旋转自由度，贴上 2 维的圆 S1，用 2 个数。

台阶二：空间姿态——贴上 4 维超球

3D 姿态有 3 个旋转自由度，同样的病同样的药：旋转空间本身是弯曲的（欧拉角的奇点、 插值的扭曲都是弯曲的症状），要把它摊平，得贴到一个更高一维的球面上。 地图铺在平面上必然在边缘撕裂，裹成地球仪就处处光滑——旋转空间需要的「地球仪」 是 4 维球面 S3：4 个数 + 单位约束（‖q‖=1）= 3 个自由度。 在这张 4D 球面上，姿态相乘是光滑的乘法、姿态插值是球面上的大圆（Slerp）—— 一切病都治好了。

彩蛋：为什么没有「三元数」

2 个自由度对应的球面是 S²，那 3 个数（一个方向 + 一个角度）为什么不行？ 因为 S² 上无法定义无奇点的乘法——拓扑学里的「毛球定理」说： 球面上的毛发（向量场）不可能处处梳理光滑，总有一个旋涡。所以 3 分量的数系不存在—— 哈密顿为寻找它苦思十年，1843 年 10 月 16 日在都柏林布鲁姆桥上豁然开朗，刻下 i² = j² = k² = ijk = −1——放弃三元数、接受第四个数的瞬间，就是四元数诞生的瞬间。

姿态的数学表示：为什么是四元数

姿态是一个旋转

无人机在空中任意朝向，可以理解为「机体坐标系」相对「世界坐标系（NED）」做了一次刚体旋转。 所有姿态表示方法都在回答同一个问题：怎么用一组数描述这次旋转？ 数学上，姿态是特殊正交群 SO(3) 中的一个元素 R——满足 RTR = I、det R = 1 的 3×3 矩阵， 自由度是 3（旋转群的维数）。任何表示法都必须恰好编码这 3 个自由度，且最好处处无奇异。

欧拉角：直观但有奇点

最直观的表示是三个角：横滚 φ、俯仰 θ、偏航 ψ，按固定顺序（本项目用航空惯例 ZYX）三次旋转的复合：

R = Rx(φ) · Ry(θ) · Rz(ψ)

问题出在 θ = ±90°：第二次旋转把第一、三次旋转的轴转到同一根轴上，三个角只剩两个有效自由度， R 的逆映射不唯一（同一个姿态对应无穷多组 (φ, ψ)）——这就是万向节锁，「万向节锁」视图里两环变红、 演示按钮证明「横滚 60°」与「偏航 60°」得到同一姿态，正是这件事的机械版本。 此外欧拉角还有两个隐患：三个角各自独立插值时合成旋转路径会扭曲（见 Slerp 一节）； 两个姿态相加必须过矩阵或三角函数，没有简单的代数结构。

四元数定义

四元数用一个实部加一个三维虚向量表示旋转，共 4 个数：

q = w + x·i + y·j + z·k　　　记作　q = [w, v] 约束（单位四元数）　w² + x² + y² + z² = ‖q‖² = 1

单位约束把 4 个数压回 3 个自由度。i、j、k 是三个虚单位，满足 i² = j² = k² = ijk = −1。 四元数乘法（Hamilton 积）由这套规则代数展开，写成向量形式最紧凑：

q₁ ⊗ q₂ = [w₁w₂ − v₁·v₂,　w₁v₂ + w₂v₁ + v₁×v₂]

注意点积项和叉积项同时出现——这个乘法不满足交换律（q₁⊗q₂ ≠ q₂⊗q₁）， 这不是缺陷而是特性：旋转本身就与顺序有关（先偏航后横滚 ≠ 先横滚后偏航）， 乘法的不可交换性恰好编码了旋转的顺序性。复合两个旋转就是一次乘法：q = q₁ ⊗ q₂，这是四元数最大的工程优势。

旋转公式：q 怎么转动一个向量

把向量 v 写成纯四元数 (0, v)，单位四元数 q 对它的作用是「三明治」：

v' = q ⊗ (0, v) ⊗ q*　（q* = [w, −v] 为共轭）

展开后 v' 的实部严格为零、向量部分是 v 被旋转后的结果——代入上面乘法公式可逐项验证 （实部：−⟨qv⟩ + ⟨vq*⟩ 类交叉项全部抵消）。为什么恰好是旋转？ 直觉来自轴角视角：任何单位四元数都能写成

q = [cos(θ2),　n · sin(θ2)] ——绕单位轴 n 转 θ 角（半角编码）

把它代入三明治公式作用在 v 上，结果正是 v 绕 n 旋转 θ（Rodrigues 公式的四元数形式）。 半角 θ/2 是关键：三明治结构里 q 出现两次，每次贡献一半旋转。 也正因为「四元数空间转 π 对应物理转 2π」，绕 n 转 360° 得到 −q 而不是 q—— 这就是 q 与 −q 表示同一旋转（双重覆盖）的根源，「四元数」视图的并排演示可验证：代数上， 上面 R(q) 的每个元素都只含 w²、v²、wv 这类二阶量，全体变号不变：

R(q) = 1 − 2(y² + z²)2(xy − wz)2(xz + wy)2(xy + wz)1 − 2(x² + z²)2(yz − wx)2(xz − wy)2(yz + wx)1 − 2(x² + y²)　　⇒　R(−q) = R(q) （矩阵元素全是 w、x、y、z 的二阶量——全体变号，矩阵不变）

这个矩阵就是四元数与旋转矩阵的换算桥：解算算法全程用四元数（乘法快、无奇异）， 只在输出给人看时换成欧拉角。代码中 qToEuler / qFromEuler 实现的正是 R 的元素提取与回填。

选择四元数的完整理由：4 个数存 3 自由度（比 9 元素矩阵省）；无奇点（任意 θ 都良定义）； 复合 = 一次乘法（欧拉角要过矩阵）；插值有闭式解 Slerp；数值漂移只需一次归一化即可修复。 代价只有两个：不直观（所以本装置花三个视图让它直观）、双重覆盖（Slerp 需短路径处理）。

四种姿态表示：一个都不能少

工程与惯导讲义（如武汉大学 i2Nav《惯性导航姿态算法》）把姿态表示总结为四种。 它们不是竞争关系，而是各管一段：四元数做主表示、矩阵做投影、旋转矢量做差值、欧拉角做人机界面。

① 欧拉角 (φ, θ, ψ)：三个数，直观，有奇点

按固定顺序三次旋转（ZYX）。三个数、人人看得懂；代价是 ±90° 俯仰奇点（万向节锁）与 更新方程里的 tanθ 发散项。它最适合出现在屏幕上给人看，不适合出现在算法里被积分。

② 方向余弦矩阵 DCM：九个数，天生是「查表器」

3×3 矩阵 C，满足 CTC = I、det C = 1。它就是本页姿态表示一章里那张 R(q) 表—— 作用向量就是一次矩阵乘（本装置加计投影 RT(q)·g 用的正是 DCM 的列）。更新方程 C = C·[ω]× 线性无奇点，但 9 个数背 6 个约束（冗余），插值与存储都不方便—— 它是「计算的工具」，不是「保存的姿态」。

③ 等效旋转矢量 φ = θ·n：三个数，「最小」的表示

方向 = 旋转轴 n，长度 = 转角 θ。3 个数、零冗余、无奇点，是姿态「差值」的天然语言： 两个姿态的差 q₁−1⊗q₂ 取其向量部分就是旋转矢量。高精度捷联惯导的姿态更新以它为标准 （圆锥补偿理论使单周期转动误差最小）。本装置四元数视图的「轴角箭头」演示， 用的就是它拆开的形式（单位轴 + 角度）。

④ 四元数：四个数，工程主流

i、j、k 到底是什么

从虚数 i 说起：i 就是「转 90°」的记号

中学里「i 是 −1 的平方根」其实隐藏了它的几何身份：把平面上的数乘以 i， 等于把它的方向逆时针转 90°。连乘两次 i（= i²）转 180°——一个向量转 180° 恰好变成自己的相反数，所以 i² = −1 不是怪谈，而是「转半圈 = 掉头」的代数写法。

搬到空间：i、j、k 是三根轴上的「转 180°」

四元数把这套记号搬到三维：i、j、k 分别表示绕 x、y、z 轴转 180°。 于是 i² = −1 的空间含义是：绕 x 轴转 360°，机体回到原样， 但四元数却整体变号（q → −q）——转一圈不等于没转，转两圈才真正回位。 这正是双重覆盖的机理，也是物理里「4π 才恢复」种种现象（狄拉克皮带戏法）的数学根源。

三个记号之间的乘法（顺序敏感）：

i×j = k　　j×k = i　　k×i = j j×i = −k　 k×j = −i　 i×k = −j　　（交换顺序 = 结果变号 = 转动顺序不可交换） i² = j² = k² = i·j·k = −1

反射 vs 旋转：一个共轭的差别

三明治乘法有两种包法：q v q* 是旋转（保持长度与手性）； q v q（两边同号）是反射——把向量镜像过一张平面，该平面的法向量就是 q 的虚部。 反射会把世界左右互换（镜子里的小人用左手）。一个巧妙的实际应用： 河面倒影测深（UIUC 笔记的场景）——把河面当作镜面，用反射四元数直接把相机观测折算到 水下景物的对称位置。两次反射复合 = 一次旋转，这也是旋转三明治公式的另一种来历。

进阶：四元数还能写成 2×2 复矩阵（w+iz 与 ix+y 等），单位四元数恰好构成矩阵群 SU(2)； 「q 与 −q 是同一旋转」用代数说就是 SO(3) 是 SU(2) 除以 ±1 的商群——双重覆盖的正式表述。

传感器测量模型：每个传感器到底测到什么

推导融合之前必须先弄清输入。每个传感器 = 一个「理想观测量」+ 一串误差项，写成方程一目了然。先看它们各自的物理原理：

  • 陀螺仪（MEMS）：内部有一个持续振动的小质量块。机体旋转时，质量块因「科里奥利效应」受到侧向力，电容测出这个力 → 角速度。它测的是转速，不是角度。
  • 加速度计（MEMS）：一个挂在弹簧上的小质量块。机体加速或被重力拉扯时质量块位移，电容测出位移 → 等效加速度。它分不清「重力」和「运动加速度」——这是后面一切麻烦的根源。
  • 磁力计：磁阻/霍尔元件测三个方向的磁场强度。地球磁场在几千米范围内近似恒定，所以它是一个天然的指南针。

陀螺仪：测角速度

ωg = ωtrue + b(t) + n(t)　（机体系三轴角速度）
变量　ωg：陀螺仪读数　ωtrue：真实角速度　b：零偏（慢变恒定偏差）　n：白噪声（每帧独立）

b 是零偏：温度漂移、启动误差造成的慢变恒定分量（真实 MEMS 陀螺仪约 0.1–2 °/s，本装置滑块 0–5）； n 是白噪声：每帧独立的随机分量。关键在于陀螺仪输出的是角速度——姿态必须由它积分而来， 而积分对恒定误差毫无抵抗力：任何 b 都会以 dθ/dt = b 的速度累积成姿态偏差（漂移），噪声则累积成随机游走。

加速度计：测比力

fb = RT(q)·(aworld − gworld) + 噪声　（机体系）
变量　fb：机体系比力　RT(q)：世界→机体的旋转　aworld：运动加速度　gworld：重力（NED 系 = [0, 0, +9.8]）

加速度计是「比力」传感器：它测量支撑力产生的等效加速度，等于运动加速度减去重力。 NED 系里重力 g = [0, 0, +9.8]（z 向下）。无人机静止或匀速（悬停微扰近似成立）时 aworld ≈ 0，于是：

fb ≈ −RT(q)·g　　即「重力方向在机体系的投影」

也就是说：水平放平时加速度计读数 ≈ [0, 0, +9.8]（z 轴朝下所以是正的，与「机体轴 z 下」的约定一致）； 机头抬起 θ，读数变成 [−9.8·sin θ, 0, +9.8·cos θ]——仅由两个分量做 atan2 就能反解出横滚和俯仰 （roll = atan2(fy, fz)，pitch = atan2(−fx, √(fy²+fz²))）。 但机动时 aworld ≠ 0，输出混入运动加速度——加速度计「分不清重力与加速」，这就是它的死穴， 也是「机动线加速度」滑块模拟的现象。另外注意：绕重力轴（偏航）旋转时 fb 完全不变——加速度计天生测不出偏航。

磁力计：测磁场方向

mb = RT(q)·mworld + 硬铁偏移 + 软铁畸变 + 干扰 + 噪声

地磁场在世界系近似为常向量。本装置设定磁倾角 49°（中国中纬度典型值），即 mworld = B·[cos δ, 0, sin δ]（B ≈ 50 μT，水平分量指北、垂直分量向下）。 磁力计给出第二个不共线的参考方向：重力管「哪边是下」，磁场管「哪边是北」——两个方向联合起来唯一确定姿态。 干扰项是真实工程痛点：机架硬铁（常值偏移）与电机通电磁场（随油门交变）会歪曲 mb， 对应「磁干扰强度」滑块；水平分量被污染的直接后果是偏航被拉偏。

小结： 　陀螺仪——快、全轴、但积分必漂 　加速度计——定横滚俯仰、机动失效、不管偏航 　磁力计——定偏航、怕电磁干扰

陀螺仪积分方程：q = 12 · q ⊗ ω 的完整推导

这是整条流水线的「预测」引擎。先把问题说成大白话：我知道「这一瞬间我在往哪个方向转、转多快」， 该怎么更新「我的姿势」？推导分四步，每步后面附一句白话。

第一步：微小旋转的四元数

设 t 时刻姿态为 q(t)。之后 dt 内，机体以角速度 ω（机体系表示）转了一小格：绕轴 n = ω/‖ω‖ 转了 dθ = ‖ω‖·dt。由轴角公式，这个小旋转的四元数是：

dq = [cos(dθ2),　n·sin(dθ2)] 　≈ [1,　n·dθ2] 　= [1,　ω·dt2] （小角度近似：cos x ≈ 1，sin x ≈ x——系数 12 的来源）

白话：转得非常少的时候，「旋转四元数」退化成「1 + 转轴方向 × 半个转角」。系数 12 在这里就出现了——它来自四元数的半角表示，不是人为凑的。

第二步：左乘还是右乘

新姿态 = 旧姿态 ∘ 小旋转。复合用四元数乘法，但乘法不可交换，放左边还是右边有本质区别： 世界系表示的增量旋转左乘，机体系表示的增量旋转右乘。 陀螺仪装在机体上，输出天然是机体系角速度，所以是右乘：

q(t + dt) = q(t) ⊗ dq　=　q(t) ⊗ [1, ω·dt2]

白话：右乘的增量活在「被 q 转过的坐标系」里——正是机体自己的坐标系。 想象你先朝北再右转 90°，和先右转 90° 再朝北，走出的方向完全不同：旋转与顺序有关，乘法次序就编码了这件事。 （若拿到的是世界系角速度，则改用左乘 q = 12 · (0, ωworld) ⊗ q。）

第三步：取导数极限

q(t) = limdt→0 q(t+dt) − q(t)dt = q(t) ⊗ [0, ω2] ⇒　q = 12 · q ⊗ (0, ω)
变量　q：q 的时间导数　dt：积分步长（本装置 2 ms）　ω：机体系角速度

白话：把「新姿态 − 旧姿态」除以时间就是变化率；实部相乘得 0（[1,·] 的实部 1 减去后归零），推导完毕。

这个方程说明：姿态四元数的运动完全由机体系角速度驱动，且是线性微分方程—— 没有三角函数、没有奇点，任意姿态下同样成立。对比欧拉角速率方程 φ = p + q·sinφ·tanθ + r·cosφ·tanθ …：在 θ=90° 处直接发散，这就是数学层面的万向节锁。

第四步：离散化——代码里每 2 ms 做什么

500 Hz 解算把连续方程变成每帧一步。两种常用离散化：

一阶（快）　q ← q ⊗ [1, ω·dt2]，然后归一化 精确（本装置用） 　Δq = [cos(‖ω‖·dt2),　ω‖ω‖·sin(‖ω‖·dt2)] 　q ← q ⊗ Δq

白话：「精确」式其实就是轴角公式本身——把一帧内的角增量 ‖ω‖·dt 当作完整旋转处理，大角速度下也不失真。 最后归一化 q ← q/‖q‖ 修掉浮点累积的模长漂移，四元数数值稳定的全部维护成本就这一步。

漂移从哪里进来

把测量模型代入：积分器实际拿到的是 ωg = ωtrue + b + n，于是：

dθ误差dt = ‖b‖　（零偏 → 姿态角线性漂移） 噪声 n → 随机游走（方差随时间线性增长）

零偏 1 °/s 跑 60 秒就是 60° 的偏差——「横滚 360°」剧本里红线飞走的原因。 预测一步无法自救，必须引入不漂的观测来持续纠偏：进入下一节「误差与修正」。

误差的定义：两个「下」方向的叉积

修正的前提是先量化「姿态错了多少、往哪个方向错」。全靠一个优雅的构造——叉积。

两个重力方向

同一个物理向量「重力」，可以由两条独立途径得到它在机体系的表示：

预测　gb = RT(q)·gworld　　——拿当前估计姿态把世界系重力旋进机体系（代码 qRotInv） 实测　ab ≈ −RT(qtrue)·gworld　——加速度计直接测出（静止/匀速时）
变量　gb：预测的「下」（我以为）　ab：实测的「下」（加速度计）　q：估计姿态　qtrue：真实姿态

白话：gb 是「我以为的下」，ab 是「实际测到的下」。 若姿态估计完全正确，两者严格重合；姿态有偏差，两个箭头就岔开一个角度 θerr。 玻璃盒的白箭头（预测 g）与品红箭头（实测 a）展示的正是这两个向量。

叉积为什么能编码旋转误差

e = ab × gb ‖e‖ = ‖a‖·‖g‖·sin θerr ≈ θerr（小角度时）

三个性质凑成一个近乎完美的误差信号：

  • 方向——右手定则给出的叉积方向，恰好是「把 gb 拧到 ab 所需的旋转轴」。白话：像拧螺丝，叉积告诉你该往哪边拧。
  • 大小——sin θerr 在小角度下 ≈ θerr，误差角越大修正越强（天然的 P 控制器）。
  • 零点——两向量重合时 e = 0，正负号自动指示转过头还是没转够。

也就是说，e 是一个「机体系下的姿态误差角速度」：把它叠加进陀螺角速度， 积分出来的效果就是把姿态往观测方向拉——修正与预测共用同一条积分通道，这是四元数框架最漂亮的地方。

什么时候这个误差不可信

推导假设「ab ∥ 重力」。机动时 ab = 重力 + 运动加速度，方向被拉偏，e 就是错的。 检测手段很简单：‖ab‖ 应恒等于 g = 9.8，明显偏离即受扰（本装置的加速度幅度门控 + 面板红色提示）。 受扰时降低修正权重甚至暂停修正，让陀螺仪独挑——「剧烈机动」剧本下误差曲线先抬头后快速回落， 正是「机动中靠预测、机动后靠观测追回」的完整过程。

本装置的「两道防线」其实是同一件事——观测可信度管理：① 幅度门控（互补/Mahony/Madgwick 用）： ‖a‖ 偏离 9.8 超过 35% 即降权或暂停加速度计修正；② 新息门控（卡尔曼用）：观测与预测的 夹角超过 40° 即判为野值丢弃。前者看「测量本身正不正常」，后者看「测量与预测合不合拍」—— 共同守住「坏观测不如没观测」。

修正律：从互补滤波到卡尔曼

有了误差信号 e，最后一步是「拿 e 怎么办」。四种算法给出了四种回答， 本节给直觉与核心公式；每种算法的完整讲解（含调参与适用场景）见文档另一模块「滤波算法讲解」。

互补滤波：欧拉角域的加权平均（暖身）

最朴素的融合在欧拉角域直接混合两条信息：

φ ← φ + (ωx + α·(φacc − φ))·dt　（俯仰同构）

白话：陀螺仪积分提供高频细节，加速度计反解角 φacc 提供低频锚点，α 决定「每秒拉近多少」。 滑块「互补 α」调的就是它。缺点：工作在欧拉角域（继承奇点）、无积分项（消不掉零偏）。

Mahony：把误差注入陀螺仪通道

Mahony 把上面的思想搬到四元数域，并把修正量定义为「额外的角速度」：

e = ab × gb　　　　　　　　　　　（重力对齐误差） ωused = ωg + Kp·e + Ki·∫e dt　　（e 的方向即「把 ĝ 拧向 a」的轴——顺着它加，姿态被拉回观测） q = 12 · q ⊗ (0, ωused)　　　　　（照常积分）
变量　e：误差向量　Kp：比例增益（弹簧刚度）　Ki：积分增益（账本速率）　∫e dt：误差累积量

白话：Kp 像弹簧刚度——偏得越多拉得越快；Ki 像一个慢慢学习的学生——它盯着「总是差的那一点」， 把原因（陀螺仪零偏）记在账上并持续补偿。Ki 的自动消零偏机制：稳态时若陀螺仪有恒定零偏 b， 姿态会维持一个恒定小偏差；积分项持续累积这个误差，直到最后整个修正由 I 项独自承担、 P 项归零、姿态误差也归零——积分器自己「学会」了零偏的补偿值。 面板「P-I 占比条」在带零偏稳态运行时 I 份额上升，演示的正是这个过程；把 Ki 调 0，误差会停在一个不为零的小稳态。

Madgwick：优化视角的梯度下降

Madgwick 换一种哲学：姿态估计是一个最优化问题——找一个 q，使「预测重力」与「实测重力」最接近：

f(q) = ‖ q* ⊗ (0, gworld) ⊗ q − (0, ab) ‖²　　（目标函数：预测 vs 实测的残差平方）
变量　f：目标函数（越小姿态越准）　q*：共轭四元数　gworld：世界系重力方向　ab：实测方向

f(q) 越小姿态越对。对 f 求关于 q 的梯度，每步沿负梯度走固定步长 β：

q = qgyro − β · ∇f(q)‖∇f(q)‖ （陀螺仪预测 + 一步下降）
变量　qgyro：陀螺积分项　β：下降步长（≈修正角速度上限）　∇f：目标函数梯度（最陡上升方向，取负即下山）

白话：像蒙着眼下山——感受脚下哪边更陡（梯度），朝下坡方向迈一小步（步长 β）。 β 一个参数同时承担 Mahony 中 Kp 的角色。与 Mahony 的实际差别：无积分项（恒定零偏留下小稳态误差）、 计算量更小、参数更少。本装置用解析梯度，并让磁修正作为独立的偏航方向分量并入， 避免大倾斜时两种梯度相互抵消。

卡尔曼滤波：按「方差」最优加权

前三种的修正增益都是固定的（Kp/β/α 是常数）。卡尔曼滤波多问了一句： 「此刻我更该信谁？」它同时维护预测的不确定度（方差 P，由过程噪声 Q 驱动）与 观测的不确定度（观测噪声 R），按两者之比计算最优增益：

K = P·HTH·P·HT + R 　K 大 → 多信观测 　K 小 → 多信预测
变量　K：卡尔曼增益（此刻信观测几成）　P：预测的不确定度（协方差）　H：观测矩阵　R：观测噪声方差

机动中预测方差大、且加速度计受扰被门控 → 自动偏信陀螺仪；静止时观测准 → 自动偏信加速度计。 本装置实现的是飞控标准的误差状态卡尔曼滤波（ES-EKF/MEKF）：协方差维护在 6 维误差状态 [姿态小角误差 δθ, 陀螺仪零偏误差 δb] 上——它还能顺带估计出零偏（面板可见）， 这是前三种算法（除 Mahony 的 I 项外）做不到的。逐步推导见「滤波算法讲解」模块。

磁力计与 MARG：补上偏航这一块

上一节的修正律有个盲区：e = a × g 里，绕重力轴旋转的两个向量都不动——加速度计误差对偏航严格不敏感。 于是纯 IMU 的偏航完全由陀螺仪积分决定，零偏一来就漂（勾掉「启用磁力计」可现场验证）。 磁力计补上缺失的第二个参照向量：重力定义「下」，磁场水平分量定义「北」，两个不共线方向唯一固定姿态的三个自由度。

倾斜补偿航向

磁读数 mb 在机体系里，要先去掉横滚俯仰的影响才能问「北在哪」。设加速度计已给出 φ、θ，标准公式：

mx' = mx·cos θ + my·sin φ·sin θ + mz·cos φ·sin θ my' = my·cos φ − mz·sin φ ψmag = atan2(−my', mx')

几何意义：把磁向量先「摆平」到水平面，再取其在水平面内的方位角。 本装置互补滤波的 MARG 模式就用这个 ψmag 替换陀螺仪偏航（低频锚点）。

MARG 在两种融合律里的形态

Mahony：与重力完全对称。用估计姿态把世界磁场旋进机体系得预测 mb = RT(q)·mworld， 磁误差 em = mb × mb，其 z 分量并入总误差的偏航通道——重力误差管横滚俯仰，磁误差管偏航，各司其职。 Madgwick：磁修正作为独立的「绕机体系 z 轴」方向分量与重力梯度并列（本装置实现）， 避免大倾斜时两种梯度相互抵消。互补：直接用 ψmag 替换偏航积分值。

干扰的数学后果：硬铁偏移给 mb 加一个常向量 → 水平分量方向恒偏 → 偏航被拉到一个稳定错误值（「磁干扰强度」滑块 + MARG 开启时的现象）； 电机交变场则让偏航抖动。真实飞控的上电校准（转圈拟合硬铁球）与自适应估计就是在解这个问题。 另注意磁北 ≠ 真北：磁偏角（declination）需要查表补偿，本装置未模拟。

Slerp：球面线性插值的推导

姿态估计解决「现在在哪」，插值解决「怎么从 A 平滑走到 B」——相机动画、云台轨迹、关键帧过渡都要它。 「四元数」视图演示的就是这个问题。

理想路径是什么

「匀速走最短路径」在旋转群上的对应物：绕一根固定轴、以恒定角速度从起点转到终点。 机头上任意固定点因此扫出球面的一段大圆弧（球面上两点间的测地线）。四元数视图里的白弧就是它。

公式与推导要点

设单位四元数 q₀、q₁，它们在四维球面上的夹角 Ω 由内积给出：cos Ω = q₀·q₁。Slerp 公式：

slerp(q₀, q₁, t) = sin((1−t)Ω)·q₀ + sin(tΩ)·q₁sin Ω t ∈ [0, 1]　（cos Ω = q₀·q₁：两四元数在 4D 球面上的夹角）

推导思路：待求曲线是四维球面（单位四元数流形）上连接 q₀、q₁ 的一段圆弧， 在 q₀、q₁ 与原点张成的二维平面内参数化——这正是一维「角度插值」在球面上的推广（平面线性插值的球面正弦加权版）。 验证性质：t=0、1 处端点正确；曲线与 q₀ 的夹角随 t 线性增长（恒定角速度）；整条曲线模长恒 1。

短路径处理：双重覆盖的实际代价

q 与 −q 表示同一旋转 ⟹ q₁ 和 −q₁ 都是合法终点。若 cos Ω = q₀·q₁ < 0（两点「隔着半个球」）， 直接插值会走超过 180° 的远路；先把 q₁ 翻成 −q1 再插，Ω 减半、路径最短。 这是实现 Slerp 的标准第一步（代码 qSlerp 的短路径分支）。

欧拉插值为什么「扭」

对 (φ, θ, ψ) 三个分量各自线性插值，等价于每一步都按新角度重新合成旋转—— 瞬时旋转轴本身随 t 连续漂移，机头轨迹偏离大圆、角速度先快后慢（三通道转角分布不均）。 单轴旋转时两者退化重合；多轴复合时中点差异可达 50° 以上（预设姿态对「水平 → [140°, 70°, 160°]」实测 51.6°）。 拖动插值进度 t 到 0.5，白球与品红球在球面上的分离度就是两种表示的差距。

立体投影：把 4D 超球压进 3D

四元数活在 4 维超球面 S3 上，人眼看不见 4D——但有一个经典技巧能把整个超球「压」进 3D： 立体投影（eater.net 可视化教程的核心手法）。想象从超球的「南极」(−1,0,0,0) 打一盏灯，S3 上每个点 q 的影子落在 w=0 的三维屏幕上：

p(q) = (x, y, z)(1 + w) （从南极 (−1,0,0,0) 投影到 w = 0 超平面）
变量　p(q)：q 的 3D 投影位置　(x,y,z)：四元数虚部　w：实部（决定点在球内/球外）

三条关键性质（都可以在「四元数」视图的 4D 立体投影 模式里亲眼验证）：

  • 赤道 = 参考球面：w=0 的四元数（如基向量 i、j、k）投影后恰好落在单位球面上——视图里的半透明球就是 4D 超球的「赤道圈」。
  • 内外有别：w>0 的点投在球内（单位 q 在球心），w<0 的点投在球外——「北半球」被压进球里、「南半球」被翻到球外。
  • q 与 −q 是一对倒易点：|p(q)|·|p(−q)| = 1——一个离球心多近，另一个就离球心多远，方向大致相对。它们是 4D 球面上的对径点（连线过 4D 球心），投影后变成「内外呼应」的一对。

玩法：切到「四元数」视图 → 演示模式选「4D 立体投影」，点「左乘 i」。 每按一次，q 沿超球面上的大圆走 180°，投影点划出一条弧线； 连按两次 i：q 精确走到 −q（青点跳到球外、品红点换进球内），而中央 3D 四轴的姿态纹丝不动—— 4D 球上走了一整圈、3D 世界只转了 360° 的一半效果。这就是双重覆盖最直观的形态， 也是「转 360° 不等于没转」的几何现场。

同一手法反过来用就是「4D 里的乘法可视化」：左乘 i 是 4D 空间里的一次刚性旋转， 整个超球在转、我们看到的投影是它的影子在变形——影子世界里的曲线运动，全是 4D 直线/圆周运动的投影。

一帧之内：完整算法流程

把所有推导串起来，就是 500 Hz 循环里每 2 ms 发生的事：

读入　ω ← 陀螺仪（含零偏+噪声）　a ← 加速度计　m ← 磁力计（MARG 开时） ① 预测　ωused ← ω + ωcorr（上一帧算出的修正） 　　　　Δq ← [ cos(‖ωused‖·dt2), ωused‖ωused‖·sin(‖ωused‖·dt2) ] 　　　　q ← q ⊗ Δq ② 门控　‖a‖ 与 9.8 明显不符 → 判定受扰，跳过观测修正（黏滞 1.5 s） ③ 误差　e ← a × RT(q)·g_world　　　　　　　　（重力：横滚俯仰） 　　　　e_z ← 磁误差 z 分量　　　　　　　　　　（磁场：偏航，MARG 开时） ④ 修正　ωcorr ← Kp·e + Ki·∫e dt　（Mahony） 　　　　或 q ← qgyro − β·∇f‖∇f‖　（Madgwick） ⑤ 维护　q ← q‖q‖　　　　　　　　　　　　　（归一化，全部维护成本） 输出　每 40 ms 记录曲线点；qToEuler 换算欧拉角供显示

每一行都能在装置里找到对应的可见现象：

  • ① 预测 → 切「纯陀螺仪积分」看它独自工作的漂移；
  • ② 门控 → 剧烈机动时玻璃盒的红色「受扰」提示与品红箭头降饱和；
  • ③ 误差 → 玻璃盒两根箭头的夹角与「重力对齐差」读数；
  • ④ 修正 → 面板「修正」三轴读数与 P-I 占比条；
  • ⑤ 归一化 → 读数 chip 里 q 的模长恒为 1。

至此完整链条闭合：传感器测量模型 → 姿态的四元数表示 → 陀螺仪积分预测 → 叉积观测误差 → 反馈修正 → 归一化输出， 外加插值应用（Slerp）与表示缺陷警示（万向节锁）。建议回到四轴姿态视图，用「手动控制」模式拖动滑块， 对照本文逐行观察这套流水线的实时运转。

工程实践备忘：面板滑块背后的真实世界

以下是真实飞控与组合导航（参考北航 Rfly 课程、武大 i2Nav KF-GINS 架构）里与本装置各滑块对应的工程惯例。

传感器标定：三条默认流水线

  • 陀螺仪零偏——上电静置数十秒取三轴均值（本装置卡尔曼滤波在线估计 |b| 是它的「运行时版本」；Mahony 的 Ki 积分项同理）。温度漂移明显时先预热再标。
  • 加速度计——六面标定：沿 ±x/±y/±z 各面静置，取均值解出零偏与刻度因子（对应「加速度计噪声」背后的系统性误差项）。
  • 磁力计——整机水平慢转几圈采样：硬铁偏移表现为点云整体平移（椭球中心偏离原点），软铁畸变表现为椭球轴向伸缩；拟合椭球即可补偿——这正是「磁干扰强度」滑块模拟、且文档反复强调「实际飞控需要磁强计校准」的那件事。

初始对准：冷启动的姿态从哪来

静止时加速度计直接给出横滚/俯仰（atan2 公式），磁力计经倾斜补偿给出偏航—— 这就是「对准」，与本装置互补滤波的公式完全同源。对准之后才切到积分+修正的运行模式。

实际飞控的 ESKF 长什么样

组合导航级（如 KF-GINS）的误差状态卡尔曼滤波状态向量扩展为 [姿态误差 δθ, 速度, 位置, 陀螺零偏, 加速度计零偏]，观测来自 GNSS/里程计等； 还有杆臂效应、地球自转补偿等高阶项。本装置的 6 维 [δθ, δb] 是它的姿态-零偏子集， 教学取舍是合理的：结构相同、维度更小。

一句话：面板上每个「误差滑块」，在真实工程里都对应一条成熟的标定/估计流水线——演示装置把流水线简化成滑块，正是为了让「病」可以随手调出来看。

全景：所有算法共享同一个框架

五种算法（含纯陀螺仪积分）都可以装进同一个「预测—修正」框架：预测用陀螺仪积分推算下一刻姿态； 修正用加速度计/磁力计的绝对方向观测纠正预测。它们的全部区别只在两件事：

  • 在哪个体空间工作——欧拉角（互补）还是四元数（其余全部）；
  • 修正增益怎么定——固定比例（互补 α / Mahony Kp / Madgwick β）还是按方差自适应（卡尔曼）。
预测（人人相同）　q ← q ⊗ Δq(ω·dt) 修正（各显神通）： 　互补——欧拉角加权 　Mahony——P/I 反馈 　Madgwick——梯度下降 　卡尔曼——方差加权

对照曲线看：纯陀螺仪积分只有预测（红线漂移）；后四者多一条修正通道（橙/蓝/绿/品红），差距全在修正的品质。

互补滤波：最直观的入门方案

核心思想 频域互补

一句话：陀螺仪高通 + 加速度计低通，两路取长补短。参数：互补 α 滑块。

数据流：陀螺仪积分得到姿态角 → 加速度计 atan2 反解出倾角 → 两者差乘 α 折回积分通道。偏航来自陀螺仪（MARG 开时用倾斜补偿磁航向替换）。

调参现象：α 大 → 跟随快但抖；α 小 → 平滑但慢。调到极端值对比 Mahony，能看出欧拉角域实现的局限（±90° 附近误差定义退化）。

优缺点：实现最简单、计算量最小；但工作在欧拉角域（有奇点）、无积分项（零偏留下稳态误差）。适合入门与算力极受限的场合。

Mahony：飞控里最常用的经典方案

核心思想 P/I 反馈

一句话：把「两个『下』方向的叉积」当作姿态误差，像控制系统一样经比例（Kp）+ 积分（Ki）反馈进陀螺仪通道。参数：Mahony Kp / Ki。

数据流：预测重力 g = RT(q)·ẑ → 误差 e = a × g → ω 修正 = Kp·e + Ki·∫e → 照常四元数积分。MARG：磁误差 z 分量并入约束偏航。

调参现象：Kp 大收敛快、放大噪声；Ki 负责自动学习陀螺仪零偏（调 0 可见稳态残差）。玻璃盒 P-I 占比条直观显示分工。

优缺点：结构简单、有积分通道、工程验证充分（Betaflight 系飞控的默认核心）；需要整定两个参数，Kp/Ki 相互耦合。

Madgwick：单参数的优化视角

核心思想 梯度下降

一句话：把「姿态估计」写成目标函数 f(q) = ‖预测重力 − 实测重力‖²，每帧沿负梯度走一步，步长 β。参数：Madgwick β。

数据流：陀螺仪积分项 + β·(−∇f/‖∇f‖) 合成四元数导数；磁场修正作为「绕机体 z 轴」的独立方向分量并入。

调参现象：β 与 Mahony 的 Kp 角色相同（大快抖、小慢稳）；论文推荐 ≈0.1。无积分项 → 恒定零偏留下小幅稳态误差（对比 Mahony 可见）。

优缺点：一个参数、计算量极小、姿态域无奇点；但稳态精度略逊于带积分的方案。适合算力紧张场景。

卡尔曼滤波：按不确定度最优加权

核心思想 方差自适应

一句话：不只估计姿态，还估计「估计得有多不准」（协方差 P），用它和观测噪声 R 的比值算出此刻的最优修正强度。参数：卡尔曼 Q（过程噪声）/ R（观测噪声）。

状态：姿态四元数 q + 陀螺仪零偏 b；协方差维护在 6 维误差状态 x = [δθ(3), δb(3)] 上（ES-EKF/MEKF——飞控与航天器的标准做法）。

行为：机动中预测方差大、加速度计受扰被门控 → 自动偏信陀螺仪；静止时观测准 → 自动偏信加速度计。零偏估计 |b| 在面板实时可见。

优缺点：统计最优（高斯噪声下）、能估计零偏、天然融合多传感器置信度；计算量中等、调参依赖噪声先验、野值需门控兜底。适合精度优先的飞控与组合导航。

互补滤波完整推导

从两条路的缺陷说起

第一步：单轴模型与两条观测路径

只看俯仰角 θ（其余两轴同理）。真实动力学只有一行：θ = ω（俯仰角速度）。两条路各自估计它：

路径 A（陀螺仪积分）　θg,n = θg,n−1 + ωg·dt 　　把 ωg = ω + b + n 代入并累加：θg,n = θ(t) + b·t + Σn·dt 　　→ 误差 = b·t（线性漂移）+ 随机游走：越久越差 路径 B（加速度计反解）　θa = atan2(−fx, √(fy² + fz²)) 　　静止时严格等于真值加小噪声：误差方差恒定，不随时间增长；机动时被运动加速度污染

白话：路径 A 是「好动态、坏直流」——它知道每一步怎么变，但起点和积累全靠记忆；路径 B 是「好直流、坏动态」——它每次都现场量，量得慢还容易被骗。融合就是让 A 管高频、B 管低频。

第二步：融合公式与两种等价形式

形式 A（先积分，再整体拉回）　θn = θg,n + k·(θa − θg,n) 形式 B（拉回量并入积分速度）　θn = θn−1 + ω·dt + α·(θa − θn−1)·dt

把形式 A 的积分展开：

θn = (1−k)·(θn−1 + ω·dt) + k·θa 　　　 = θn−1 + ω·dt + k·(θa − θn−1 − ω·dt) 　　　 ≈ 形式 B（k·ω·dt 是二阶小量，小 k 小 dt 时可忽略）

两种形式在 k = α·dt 下一致。本装置实现形式 B：拉回量以「角速度」的身份进入积分通道， 与后续 Mahony 的结构完全同构——理解了互补，Mahony 就只差一个积分项。

第三步：为什么叫「互补」——频域视角

对形式 A 做直觉频域分析：

  • θg 是「过去所有陀螺仪读数的累积和」——积分器。缓慢变化（直流/低频）的误差被忠实的累进去（漂移），所以它对低频不可信、高频可信：等效高通。
  • θa 是每帧独立的现场测量——高频抖动大、均值准：等效低通。
  • 融合权重 (1−k) 与 k 之和恒等于 1——两个滤波器的频率响应加起来恒为全通，刚好互补，这就是名字的由来。交叉频率 ≈ α（rad/s）。

第四步：偏航为什么丢失，以及欧拉角的死穴

θa 的公式里只有 fx、fy、fz——绕重力轴旋转时这三个数都不变， 所以互补滤波天生测不出偏航（MARG 模式用倾斜补偿磁航向 ψmag 替换，见数学原理·磁力计）。 另外当 θ → ±90° 时 atan2 的两个输入 √(fy²+fz²) 与自身都趋近退化， 倾角解算病态——这是欧拉角域实现的原罪，也是四元数算法存在的理由。

Mahony 完整推导

误差反馈 + 自动学零偏

第一步：误差信号的小角度形态

数学原理·误差一节已给出 e = a × g。小角度时它可写成：

e ≈ θerr·n　　（误差角 × 旋转轴方向）

把它加进角速度再积分，效果恰好是「把姿态朝观测方向转 θerr」——误差信号天然就是修正角速度，这是 Mahony 一切简洁性的来源。

第二步：闭环误差动力学——Kp 就是带宽

把修正代入误差的传播（忽略旋转耦合的二阶项），得到一阶线性系统：

δθ ≈ −Kp·δθ − δb　⇒　δθ(t) ≈ δθ(0)·e−Kp·t + (零偏引起的稳态项)

白话：误差像弹簧一样指数衰减，时间常数 = 1/Kp。Kp = 1 → 约 1 秒收敛；Kp 调大收敛快、但把加速度计的噪声也放大了同样倍数——这就是「快而抖」的数学形式。

第三步：Ki 消零偏——一本慢慢记账的账本

只有 Kp 时，稳态下修正必须恰好抵消零偏 b：Kp·δθ∞ = b，即姿态永远差着 δθ∞ = b/Kp。引入积分项后：

记 z = ∫e dt（账本），则 ω修正 = Kp·e + Ki·z 稳态推理：若姿态误差 δθ 不归零 → z 持续增长 → 修正持续增大 → 误差被继续压缩 最终 δθ → 0，此时修正全部由 Ki·z 提供，而它必须恰好等于 b： 　　Ki·z∞ = b　⇒　z∞ = bKi

白话：账本 z 最终「记下了零偏的大小」。此后哪怕误差归零，账本上的补偿依然在——陀螺仪零偏被静悄悄地学走了。玻璃盒 P-I 占比条里 I 的份额逐渐升高，就是这个收敛过程的现场直播。

第四步：MARG——磁场补上偏航通道

重力误差 e 对绕重力轴的旋转严格不敏感（叉积的 z 分量不含偏航信息）。 磁场提供第二个方向：预测磁向量 m = RT(q)·mworld，磁误差 (m × m) 的 z 分量 只反映「机头绕 z 轴转了多少」——并入 e 的 z 通道后，偏航被磁场约束。横滚俯仰仍由重力主导，两向量各司其职、互不打架。

第五步：与互补滤波的关系

Mahony 就是「搬到四元数域、多一个积分项的互补滤波」：Kp 对应互补 α 的角色，Ki 是全新的零偏学习通道。 因为工作在四元数域，它在任意姿态下都无奇点；因为误差沿机体系注入积分通道，它与四元数运动方程严丝合缝。

Madgwick 完整推导

把姿态解算变成下山

第一步：目标函数的逐分量展开

「预测重力」用四元数旋转公式展开（数学原理·姿态表示），减去实测，得到三个残差分量：

f(q) = 2(xz − wy) − ax2(wx + yz) − ay2(0.5 − x² − y²) − az　　　目标函数　f(q) = ‖f‖²

白话：第三行 2(0.5 − x² − y²) 就是预测重力的 z 分量 1−2(x²+y²) 的另一半——三个分量都是 q 的二次函数，所以 f 对 q 求导毫不费力。

第二步：梯度与「下山方向」

目标函数的梯度 ∇f = JT·f，其中 J 的每一行是各残差对 w/x/y/z 的偏导。将上式逐项求导并整理，本装置实现的解析形式为：

∇f 的四元数形式　s = [ −2y·f₁ + 2x·f₂, 　　　　　　　2z·f₁ + 2w·f₂ − 4x·f₃, 　　　　　　−2w·f₁ + 2z·f₂ − 4y·f₃, 　　　　　　　2x·f₁ + 2y·f₂ ]

关键观察：这个梯度方向与 Mahony 的叉积误差 e = a × g 是同一个几何对象——都是「从预测重力转向实测重力」的旋转在各自坐标系里的表达。 两种算法的差异不在「看什么误差」，而在「怎么用这个误差」：Mahony 用它造角速度，Madgwick 用它定义下降方向。

第三步：下降步与陀螺项的合成

q = qgyro − β · ∇f‖∇f‖　　（预测走大步，修正走小步）

归一化 ∇f 让 β 的量纲是「rad/s」——它直接就是修正角速度的上限：β = 0.1 意味着每秒最多拉回约 0.1 rad ≈ 5.7°。这与 Kp·e 在小误差下等价（e ≈ θerr 时 Kp·e 的量级也由 Kp 决定）。

第四步：无积分项的代价——稳态误差公式

恒定零偏 b 下，Madgwick 收敛到的平衡点由「下降步恰好抵消漂移」决定：

β · ‖∇f(q稳态)‖ ≈ b ⇒　稳态姿态误差 ≈ bβ　（小角度）
变量　b：陀螺仪零偏　β：梯度步长——零偏每小时推 b 度、下降步最多拉 β 度，平衡点即 bβ

白话：零偏每小时推着你走 b 度，下降步每小时只能拉回 β 度，两力平衡时姿态就停在差 b/β 的地方。Mahony 用账本（积分项）最终把 b 记下来，Madgwick 没有账本，只能停在平衡点——这就是两者稳态精度的差别。

第五步：磁修正为什么是「独立方向分量」

绕机体 z 轴的小旋转 δ 对四元数导数的贡献是 12·q⊗(0, 0, δ)——与陀螺项的形态完全同构，所以可以按方向并列叠加进 (dw,dx,dy,dz)，再随整帧一起积分。本装置据此让磁场只管偏航、重力只管横滚俯仰，避免大倾斜时两个梯度目标互相抵消。

卡尔曼滤波完整推导

从两台秤说起

第一步：一维卡尔曼——最优加权就是方差的反比

用两台精度不同的秤称同一物体：估计值 x（方差 P）与新测量 z（方差 R）。最优融合（最小方差线性无偏）只有一个解：

x+ = x + K·(z − x) K = PP + R 　P 很小（自信）→ K → 0 → 几乎不信新测量 　P 很大（心虚）→ K → 1 → 几乎全信测量
变量　x：原估计　x+：融合后估计　z：新测量　P：估计方差　R：测量方差——最优加权就是方差的反比

白话：卡尔曼增益 K 就是「此刻该信观测几成」。整部卡尔曼滤波 = 每帧自动更新这个「自信程度」的账本 P。这一行公式就是全部灵魂，后面只是把它搬到姿态上。

第二步：为什么不能直接对四元数用线性卡尔曼

两个障碍：① 四元数必须满足 ‖q‖=1，活在四维球面上，线性高斯假设不成立；② 观测（重力方向）是 q 的非线性函数。硬套会把 q 推出球面。

白话解法（MEKF 的核心思想）：把「大头」留给非线性方法——姿态照常用四元数积分；只把「小误差」拿出来做线性卡尔曼。小误差近似为 0，线性化成立，算完再把小误差贴回去。

第三步：误差状态与它的运动方程

误差定义　q真 ≈ q ⊗ [1, δθ2]　（δθ：机体系小角误差） 误差状态　x = [δθ, δb] 运动方程线性化 　δθ = −ω×δθ − δb − ng 　δḃ = nb

两项来历：−[ω]×δθ 是「误差向量随机体旋转而转动」（坐标系耦合）；−δb 是关键项—— 零偏估计误差会一比一冒充角速度误差，这正是「卡尔曼能学零偏」的通道：姿态误差里含有零偏的痕迹，滤波器顺着痕迹把 b 估计出来。

第四步：预测——方差怎么长大

P− = Φ·P·ΦT + Q·dt Φ = I + A·dt A = −[ω]×−I00
变量　P：6×6 误差协方差　Φ：状态转移　Q：过程噪声（陀螺仪噪声注入 δθ）　[ω]×：角速度的反对称矩阵

白话三项：① P 对角线上的姿态方差被陀螺仪噪声 ng 每秒吹大一点（Q·dt）；② 姿态与零偏之间产生负相关——「零偏估小了」意味着「预测转少了」，两者此消彼长；③ 零偏自身的方差按随机游走缓慢增长（它可能慢漂）。协方差矩阵就是这三种不确定性的记账簿。

第五步：更新——观测方程与增益

观测方程（线性化）　z = a − g ≈ [g]×·δθ + v 　⇒　H = [[g]×, 0] 增益　K = P−HTH·P−·HT + R 回填　δx = K·z 　姿态 ← q ⊗ [1, δθ2] 　零偏估计 ← b + δb 　P ← (I − K·H)·P　（不确定度收缩）
变量　z：新息（观测 − 预测）　v：观测噪声　[g]×：预测重力方向的反对称矩阵　磁场观测同构：g 换成 m 即可

磁场观测完全同构：把 g 换成预测磁方向 m 即可。本装置设 40° 新息门控——观测与预测夹角过大直接丢弃，防止机动野值把状态拽飞。

第六步：与 Mahony 的关系——自动调增益的滤波器

收敛后 P 趋于稳态，K 也随之趋于常数——此时卡尔曼的更新形式与固定增益的 Mahony 几乎一样。 区别在过渡过程：机动中 P 大 → K 自动升 → 更信观测；观测被门控 → P 继续涨但无更新 → 纯预测； 静止后 K 自动回落。可以说：卡尔曼 = 增益随不确定度自动调度的 Mahony + 显式的零偏估计器。
