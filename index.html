模拟 IMU（左上滑块）

陀螺零偏：真实陀螺的恒定偏差，是被积分进姿态、导致漂移的元凶——拉大它，红线（纯陀螺积分）会线性飞走。陀螺/加计噪声：传感器白噪声，噪声越大曲线越毛糙。机动线加速度：机动时加计除了重力还测到运动加速度，会把「下」的方向搞错——这就是机动时不能信加计的原因。电机振动：机架高频抖动的简化模型。

解算算法与显示源

「模型姿态来源」决定 3D 模型与左上读数显示哪一个结果：真实姿态是上帝视角（对照组），其余四种是算法各自算出来的。曲线区对比四种算法与真实的偏差：红 = 纯陀螺积分（只增不减的漂移）、橙 = 互补滤波、蓝 = Mahony、绿 = Madgwick、白 = 真实。图例上的数字是当前误差，点击图例可隐藏对应曲线。

玻璃盒（算法内部可视化）

勾选「显示算法内部量」后：3D 中出现两根箭头——白箭头是算法当前估计的「下」方向，品红箭头是加计实测的「下」方向。两箭头夹角就是算法当前的误差：融合算法会把它收敛到零；选纯陀螺积分则白箭头持续转偏、品红纹丝不动——漂移的现场演示。剧烈机动时品红箭头乱甩并降饱和，表示加计被线加速度污染、暂时不可信。面板同步显示陀螺输入与修正量、Mahony 的 Kp/Ki 占比条等内部量。

万向节锁视图

三轴平衡环架模拟机械陀螺仪：蓝环 = 偏航（外）、金环 = 俯仰（中）、绿环 = 横滚（内），三个滑块分别驱动。把俯仰拉到 ±90°：内环（横滚）的转轴与外环（偏航）的转轴重合，两环变红——此时横滚和偏航变成同一个动作，三个环只剩两个自由度。点「演示：只剩 2 个自由度」会自动完成整个过程：先用横滚、再用偏航各转 60°，两次得到的姿态完全相同（夹角 0.000°），证明两个自由度已经退化成一个。演示可随时暂停讲解。

四元数视图

这个视图回答「为什么用四元数插值而不是欧拉角插值」。选一个姿态对，拖动插值进度 t：白色弧是 Slerp——始终绕固定轴匀速旋转，机头在球面上画出大圆；品红弧是欧拉角逐分量插值——旋转轴本身在漂移，轨迹扭曲。多轴复合姿态下两条弧中点相差 50° 以上。青色箭头是当前姿态的轴角表示（绕哪根轴转多少度）。勾选「q 与 −q」后左右两个四轴分别按 q 和 −q 摆放——四个数全变号但姿态完全相同（永远重合），这就是四元数的「双重覆盖」，也是 Slerp 必须做短路径处理的原因。

磁力计与 MARG

加速度计测量重力，重力与偏航无关——所以纯 IMU 解算的偏航只靠陀螺积分，会持续漂移。真实无人机都装磁力计（电子罗盘）：磁场水平分量给出「磁北」方向，经倾斜补偿后约束偏航。勾选「启用磁力计（MARG）」后，三个融合算法的偏航立刻被磁场拉住、不再漂移。拖「磁干扰强度」滑块可模拟机身金属与电机通电磁场——MARG 偏航精度会下降但仍远好于没有磁力计（实际飞控需要磁强计校准）。3D 中的琥珀色箭头指示当前解算的机头方位在水平面上的投影：MARG 关时它慢慢偏离罗盘，开时自动回正。

原理速览

为什么要用四元数？

欧拉角（横滚 φ、俯仰 θ、偏航 ψ）直观，但按固定顺序旋转、只有三个自由度：当俯仰接近 ±90° 时第二次旋转轴与第一次重合，丢失一个自由度——即「万向节锁」。四元数 q = w + xi + yj + zk 用四个数表示旋转，任何姿态下都平滑无奇异，插值（Slerp）路径自然，是姿态表示的标准选择。切到「万向节锁」视图可以亲眼看到这件事。

陀螺仪为什么积分会漂移？

陀螺仪输出角速度，姿态由 q̇ = ½ q ⊗ ω 逐步积分得到。真实陀螺存在恒定零偏（bias）与噪声：零偏每秒都被积分进姿态，误差随时间线性累积。把「模型姿态来源」切成「纯陀螺积分」，即可看到它相对幻影缓缓转偏。

加速度计能帮什么忙？

静止或匀速时，加速度计测量重力方向在机体系的投影，可独立解算横滚与俯仰（但看不出偏航，且机动时被线加速度污染）。融合的思路：高频信陀螺（动态好、会漂移），低频信加计（静态准、动态差），各取所长。

三种融合算法的直觉

互补滤波：陀螺积分结果与加计姿态角按比例混合，α 控制加计权重。Mahony：把加计方向与预测重力方向的叉积作为误差，经 P/I 反馈修正角速度，是飞控最常用的方案。Madgwick：把姿态估计视为优化问题，沿目标函数梯度下降修正，单参数 β 权衡跟随速度与噪声抑制。

为什么 q 和 −q 是同一个旋转？

把四元数 q = (w, x, y, z) 全部取负得到 −q，代回旋转公式 R(q)=R(−q)——旋转矩阵完全一样。几何直觉：绕轴 n 转角 θ，等价于绕 −n 转角 −θ，即 (n, θ) 与 (−n, −θ) 是同一件事，而 −q 正好编码了后者。代价是四元数有「双重覆盖」：4 个数对应 2 种符号表示。所以插值时若两个四元数点积为负，要先翻个符号再插（Slerp 的短路径处理），否则会绕远路。「四元数」视图的 q 与 −q 演示可以亲眼看到两个四轴永远重合。

Slerp 为什么走大圆——欧拉插值的扭曲线

姿态插值的「理想路径」是旋转群 SO(3) 上的测地线：绕一根固定的轴匀速转过去，机头上任意一点在空间画出大圆弧，这就是 Slerp。而欧拉角插值路径穿过欧拉角空间，合成旋转轴本身在转——机头轨迹会扭曲、先慢后快再慢。单轴旋转时两者几乎重合；多轴复合旋转时差异可达 50° 以上。这就是为什么相机动画、关键帧姿态过渡都应该用四元数插值。

加计看不出偏航，磁力计来补——以及它怎么被干扰

磁力计测地球磁场：水平分量给出「磁北」方向，经倾斜补偿后约束偏航——这就是 MARG（磁 + 角速度 + 重力）方案。但磁力计怕干扰：机身金属产生硬铁偏移、电机通电产生交变磁场，都会把偏航拉偏。实际飞控需要上电校准或自适应滤波来对抗。另注意：磁北≠真北（磁偏角），真实产品还要做 declination 修正。

坐标系与约定

世界系 NED（x 北、y 东、z 下），机体系前右下。机体轴 x 前、y 右、z 下，所以三维场景里 z 箭头指向地面（这与「z 向上」的直觉相反，但和四元数、加速度计读数完全一致）。四元数 q 为机体系→世界系。模拟加速度计静止时输出 +g 沿机体「下」方向。解算频率 500 Hz，曲线每 40 ms 记录一点。
