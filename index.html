IMU 传感器模拟

这组滑块决定「喂给算法的数据有多脏」。真实 IMU 的缺陷可归为三类：零偏（恒定的系统性偏差）、 噪声（随机抖动）、动态误差（运动本身对测量的污染）——每个滑块对应其中一项。 左上「IMU 原始数据」chip 显示的正是经过这些污染后的实际输出，可随时对照。

陀螺仪零偏 0 – 5 °/s

是什么陀螺仪输出角速度时自带的恒定偏差——即使机体完全静止，它也一直报告一个小角速度。

起什么作用姿态完全由陀螺仪积分得到，这个偏差每一步都被积进姿态，是漂移的主要来源（推导见数学原理·陀螺仪积分方程）。

改了会怎样调大后红色曲线（纯陀螺仪积分）以更快的速度线性飞走； Mahony 的积分项会慢慢把它估计出来并抵消（把 Ki 也调到 0 可验证：只靠 Kp 时零偏永远消不掉）。

陀螺仪噪声 0 – 2 °/s

是什么陀螺仪输出的随机白噪声，叠加在真实角速度上，每帧独立。

起什么作用被积分后变成姿态上的随机游走；同时压缩了算法可用的信息量。

改了会怎样曲线整体变毛糙；融合算法会被迫调低修正增益来滤掉它（这正是 β/α 参数存在的意义）—— 噪声大时把 β 或 α 调小，曲线立刻变平滑，但跟踪变慢，两者权衡。

加速度计噪声 0 – 1 m/s²

是什么加速度计输出的随机噪声，叠加在「重力 + 运动加速度」上。

起什么作用污染算法的「观测」：加速度计是唯一的横滚/俯仰参照，噪声大时观测本身不可信。

改了会怎样玻璃盒里品红箭头（实测重力方向）开始抖动；互补/融合算法输出随之抖， 需要调小 α 或 β 来抑制。纯陀螺仪积分完全不受影响——它不看加速度计。

机动线加速度 0 – 5 m/s²

是什么机动时机体加减速产生的运动加速度。加速度计分不清重力和它——这就是「比力」的含义。

起什么作用人为制造加速度计失效场景：输出 = 重力 + 这个分量，方向随机动变化。

改了会怎样调大后剧烈机动时品红箭头明显甩偏、面板出现红色「受扰」提示、 融合算法误差曲线抬头。好算法靠「幅度门控」（测到的总量明显偏离 g 时降权）自救——幅度不同现象不同，可对比观察。

电机振动 0 – 1

是什么机架高频抖动的简化模型：叠加在陀螺仪和加速度计上的高频小幅振荡。

起什么作用模拟真实无人机最大的工程烦恼——振动频段的能量会被积分进姿态，也会污染观测。

改了会怎样曲线出现细密毛刺；500 Hz 解算完全在采样频带内，无法靠快滤掉—— 只能靠调低融合增益（β/α）或降采样，这正是真实飞控要装减震垫的原因。

解算算法

四种算法同时接收同一份脏数据、各自解算，误差曲线同图对比。思路一览：

  • 纯陀螺仪积分——只用陀螺仪，不修正。动态完美、恒定漂移，是「不融合会怎样」的对照组（红线）。
  • 互补滤波——陀螺仪积分（高通）与加速度计角度（低通）按比例混合，欧拉角域实现，最直观。
  • Mahony——把重力方向误差经 P/I 反馈注入陀螺仪积分，飞控最常用；多一个积分项能消零偏。
  • Madgwick——把姿态估计写成优化问题，沿目标函数梯度下降，单参数 β，计算量小。
启用磁力计（MARG） 开关

是什么让三个融合算法额外使用磁力计数据——MARG = 磁力计 + 角速度 + 重力。

起什么作用加速度计绕重力轴怎么转读数都不变，所以定不了偏航；磁场的水平分量提供「磁北」参照， 经倾斜补偿后专门约束偏航通道。

改了会怎样有零偏时（默认 1°/s），关掉它偏航误差持续累积、琥珀色机头箭头慢慢离开罗盘方向； 勾上后偏航被磁场拉住回正。若同时把「磁干扰强度」拉大，偏航会被拉偏一个稳定误差——磁场被污染了。

Mahony Kp 0.05 – 5

是什么比例增益：误差多大，修正角速度就给多大（e = Kp·误差）。

起什么作用决定「把姿态拉回观测」的速度。Kp 越大，加速度计的发言权越大，收敛越快。

改了会怎样调大：误差收敛明显变快，但噪声也被放大，曲线变抖；调小：平滑但慢。 极端调到 0.05：几乎只剩陀螺仪积分，慢慢漂移；调到 5：跟得很紧但毛刺明显。

Mahony Ki 0 – 0.5

是什么积分增益：误差的累积量也参与修正。

起什么作用稳态时比例项趋于零，积分项恰好收敛到「陀螺仪零偏的补偿值」—— 这是 Mahony 能自动消零偏的机制（数学上：e 的直流分量被积分器吸收）。

改了会怎样设 0：有零偏时收敛后仍留一个稳定小偏差；调大：消零偏更快，但过大会振荡超调。 配合「陀螺仪零偏」滑块做实验：Ki=0.05 时约几秒收敛到零误差，Ki=0 则永远差一点。

Madgwick β 0.01 – 1

是什么梯度下降的步长：每秒沿「预测重力与实测重力之差」的负梯度方向走多远。

起什么作用一个参数同时扮演 Mahony 里 Kp 的角色：权衡跟随速度与噪声抑制。

改了会怎样与 Kp 现象一致：大 β 快而抖、小 β 慢而稳。默认 0.1 是论文推荐的折中。 注意 β 没有积分项——对恒定零偏会留下小幅稳态误差，这是它和 Mahony 的实际差别。

互补 α 0.05 – 5

是什么互补滤波的混合权重：角度修正量 = α × 加速度计角度误差。

起什么作用α 大等于低通截止频率高——更信加速度计；等价于频域里陀螺仪高通、加速度计低通的交叉点。

改了会怎样行为与 Kp 类似但更粗糙：它工作在欧拉角域、没有积分项，且在俯仰接近 ±90° 时 误差定义本身会退化（欧拉角的固有缺陷）。调到极端值对比 Mahony，能看出「为什么飞控不用朴素互补」。

卡尔曼 Q（过程噪声） 0.01 – 2 °/s

是什么预测模型的不确定度——「陀螺仪积分这一步有多不可信」，进入协方差传播 Q·dt。

起什么作用与观测噪声 R 一起决定卡尔曼增益：Q 大 → 估计方差涨得快 → 每帧更信观测。

改了会怎样调大：跟随变快但毛刺明显；调小：平滑但机动中跟不上。设成与「陀螺仪噪声」滑块一致（0.2）即与真实噪声水平匹配。

卡尔曼 R（观测噪声） 0.005 – 1 g

是什么观测的不确定度——「加速度计/磁力计方向有多不可信」（单位 g，重力归一化后）。

起什么作用R 大 → 增益变小 → 更信预测；它同时参与 40° 新息门控的置信度评估。

改了会怎样拉到最大：几乎退化成纯积分（误差慢慢漂移）；调小：收敛极快但抖。配合「剧烈机动」剧本体验「机动中自动偏信陀螺仪」的自适应行为。

数学原理

总览：从「传感器原始数据」到「无人机姿态」

先建立一个画面：无人机悬停在空中，它自己并不知道自己是什么姿势。机体内部没有任何魔法， 只有三个小传感器各报告一条数据。姿态解算要回答的问题是—— 只凭这三条数据，如何推断出「我现在头朝哪、身子歪了多少」？

三个传感器各自能感知什么？用身体的直觉来类比：

  • 陀螺仪——像你的内耳：闭上眼睛转圈，你能感觉到「正在转、转多快」，但转完后说不清总共转了多少度（靠积累印象，会累积误差）。
  • 加速度计——像手机的重力感应或手里的水平仪：静止时能准确指出「哪边是下」，可一动起来（加减速）就乱报。
  • 磁力计——就是电子指南针：总知道磁北在哪，但怕电机与金属的磁场干扰。

三者各有所长也各有所短，谁也不能单独完成任务。解算算法每 2 毫秒（500 Hz）做一轮四步循环，把它们拧成一股：

① 预测　q̇ = ½ · q ⊗ ω　　　　陀螺仪积分：高频、动态好、会漂移 ② 观测　a ↔ ĝ　m ↔ m̂　　　 加速度计/磁力计给出「下」与「磁北」：低频、静态准、动态差 ③ 误差　e = a × ĝ　　　　　 实测方向与预测方向的叉积 = 姿态误差 ④ 修正　ω ← ω + Kp·e + Ki·∫e　（或 Madgwick / 卡尔曼的方式）→ 回到 ① 积分

一句话记住分工：陀螺仪负责「快」，加速度计和磁力计负责「准」，算法负责让快的别跑偏、准的别添乱。

对照演示装置：玻璃盒展示 ②③④（两根箭头 = ĝ 与 a，读数 = 修正量），误差曲线展示输出与真值的差， 四元数视图与万向节锁视图回答「为什么姿态要用四元数表示」。接下来按数据流顺序展开： 每一节都先给直觉、再给推导；所需的全部数学工具只有五件，见下一节。

数学工具箱：整个推导只需要这五件

全部是高中以内的数学。读后面任何一节卡住时，回到这里。

① 向量：既有方向又有长度的箭头

传感器输出的三个数 (x, y, z) 就是一个向量的三个分量。例如加速度计读 (0, 0, 9.8) 表示 「一根指向机体系 z 轴、长度 9.8 的箭头」。长度记作 ‖v‖ = √(x²+y²+z²)。 归一化 = 向量除以自己的长度，得到只表示方向、长度恰为 1 的箭头——姿态解算里几乎只用「方向」，所以到处都在归一化。

② 点积：量「两个箭头有多同向」

a·b = ax·bx + ay·by + az·bz = ‖a‖·‖b‖·cos θ。两箭头同向时取最大值，垂直时为 0，反向时为负。 用途：反查夹角（cos θ = 点积 ÷ 长度乘积）；判断两个四元数是否同指一个旋转（点积为正还是为负）。

③ 叉积：由两个箭头造出「垂直于它们」的第三个

a×b 的方向由右手定则给出——右手四指从 a 弯向 b，拇指所指就是 a×b 的方向；大小 = ‖a‖·‖b‖·sin θ。 这是整个解算最重要的工具，两个关键用途： 方向——「把箭头 ĝ 拧到箭头 a」应该绕哪根轴转（叉积方向就是那根轴）； 大小——小角度时 sin θ ≈ θ，误差越大叉积越长。融合算法的「误差信号」就是一个叉积。

④ 导数与数值积分：变化率与「下一刻 = 现在 + 变化率 × dt」

q̇ 读作「q 的导数」，含义是 q 每秒变化多少。计算机不会连续微积分，只能一小步一小步走： q(t + dt) ≈ q(t) + q̇(t)·dt，本装置 dt = 2 毫秒（500 Hz）。步子足够小时，这条折线与真实曲线几乎重合—— 这就是「数值积分」，也是陀螺仪数据变成姿态的全过程。

⑤ 小角度近似与旋转矩阵

θ 很小时（弧度制）：sin θ ≈ θ，cos θ ≈ 1。它把三角函数运算变成简单乘加——后文所有「≈」都来自这里。 旋转矩阵 R 是一张 3×3 的换算表：世界系向量左乘 R 得到它在机体系的投影，左乘 Rᵀ 则反向。 矩阵只是「查表」，推导时我会把它拆成一行行分量写出来。

姿态的数学表示：为什么是四元数

姿态是一个旋转

无人机在空中任意朝向，可以理解为「机体坐标系」相对「世界坐标系（NED）」做了一次刚体旋转。 所有姿态表示方法都在回答同一个问题：怎么用一组数描述这次旋转？ 数学上，姿态是特殊正交群 SO(3) 中的一个元素 R——满足 RᵀR = I、det R = 1 的 3×3 矩阵， 自由度是 3（旋转群的维数）。任何表示法都必须恰好编码这 3 个自由度，且最好处处无奇异。

欧拉角：直观但有奇点

最直观的表示是三个角：横滚 φ、俯仰 θ、偏航 ψ，按固定顺序（本项目用航空惯例 ZYX）三次旋转的复合：

R = Rx(φ) · Ry(θ) · Rz(ψ)

问题出在 θ = ±90°：第二次旋转把第一、三次旋转的轴转到同一根轴上，三个角只剩两个有效自由度， R 的逆映射不唯一（同一个姿态对应无穷多组 (φ, ψ)）——这就是万向节锁，「万向节锁」视图里两环变红、 演示按钮证明「横滚 60°」与「偏航 60°」得到同一姿态，正是这件事的机械版本。 此外欧拉角还有两个隐患：三个角各自独立插值时合成旋转路径会扭曲（见 Slerp 一节）； 两个姿态相加必须过矩阵或三角函数，没有简单的代数结构。

四元数定义

四元数用一个实部加一个三维虚向量表示旋转，共 4 个数：

q = w + x·i + y·j + z·k　记作　q = [w, v]，　约束　w² + x² + y² + z² = ‖q‖² = 1

单位约束把 4 个数压回 3 个自由度。i、j、k 是三个虚单位，满足 i² = j² = k² = ijk = −1。 四元数乘法（Hamilton 积）由这套规则代数展开，写成向量形式最紧凑：

q₁ ⊗ q₂ = [w₁w₂ − v₁·v₂,　w₁v₂ + w₂v₁ + v₁×v₂]

注意点积项和叉积项同时出现——这个乘法不满足交换律（q₁⊗q₂ ≠ q₂⊗q₁）， 这不是缺陷而是特性：旋转本身就与顺序有关（先偏航后横滚 ≠ 先横滚后偏航）， 乘法的不可交换性恰好编码了旋转的顺序性。复合两个旋转就是一次乘法：q = q₁ ⊗ q₂，这是四元数最大的工程优势。

旋转公式：q 怎么转动一个向量

把向量 v 写成纯四元数 (0, v)，单位四元数 q 对它的作用是「三明治」：

v' = q ⊗ (0, v) ⊗ q*　（q* = [w, −v] 为共轭）

展开后 v' 的实部严格为零、向量部分是 v 被旋转后的结果——代入上面乘法公式可逐项验证 （实部：−⟨qv⟩ + ⟨vq*⟩ 类交叉项全部抵消）。为什么恰好是旋转？ 直觉来自轴角视角：任何单位四元数都能写成

q = [cos(θ/2),　n̂ · sin(θ/2)]　——绕单位轴 n̂ 转 θ 角

把它代入三明治公式作用在 v 上，结果正是 v 绕 n̂ 旋转 θ（Rodrigues 公式的四元数形式）。 半角 θ/2 是关键：三明治结构里 q 出现两次，每次贡献一半旋转。 也正因为「四元数空间转 π 对应物理转 2π」，绕 n̂ 转 360° 得到 −q 而不是 q—— 这就是 q 与 −q 表示同一旋转（双重覆盖）的根源，「四元数」视图的并排演示可验证：代数上， 上面 R(q) 的每个元素都只含 w²、v²、wv 这类二阶量，全体变号不变：

R(q) = ⎡ 1−2(y²+z²)　 2(xy−wz)　　2(xz+wy) ⎤ 　　　　⎢ 2(xy+wz)　 1−2(x²+z²)　 2(yz−wx) ⎥ 　　　　⎣ 2(xz−wy)　　2(yz+wx)　 1−2(x²+y²) ⎦　　⇒　R(−q) = R(q)

这个矩阵就是四元数与旋转矩阵的换算桥：解算算法全程用四元数（乘法快、无奇异）， 只在输出给人看时换成欧拉角。代码中 qToEuler / qFromEuler 实现的正是 R 的元素提取与回填。

选择四元数的完整理由：4 个数存 3 自由度（比 9 元素矩阵省）；无奇点（任意 θ 都良定义）； 复合 = 一次乘法（欧拉角要过矩阵）；插值有闭式解 Slerp；数值漂移只需一次归一化即可修复。 代价只有两个：不直观（所以本装置花三个视图让它直观）、双重覆盖（Slerp 需短路径处理）。

传感器测量模型：每个传感器到底测到什么

推导融合之前必须先弄清输入。每个传感器 = 一个「理想观测量」+ 一串误差项，写成方程一目了然。先看它们各自的物理原理：

  • 陀螺仪（MEMS）：内部有一个持续振动的小质量块。机体旋转时，质量块因「科里奥利效应」受到侧向力，电容测出这个力 → 角速度。它测的是转速，不是角度。
  • 加速度计（MEMS）：一个挂在弹簧上的小质量块。机体加速或被重力拉扯时质量块位移，电容测出位移 → 等效加速度。它分不清「重力」和「运动加速度」——这是后面一切麻烦的根源。
  • 磁力计：磁阻/霍尔元件测三个方向的磁场强度。地球磁场在几千米范围内近似恒定，所以它是一个天然的指南针。

陀螺仪：测角速度

ωg = ωtrue + b(t) + n(t)　（机体系三轴角速度）

b 是零偏：温度漂移、启动误差造成的慢变恒定分量（真实 MEMS 陀螺仪约 0.1–2 °/s，本装置滑块 0–5）； n 是白噪声：每帧独立的随机分量。关键在于陀螺仪输出的是角速度——姿态必须由它积分而来， 而积分对恒定误差毫无抵抗力：任何 b 都会以 dθ/dt = b 的速度累积成姿态偏差（漂移），噪声则累积成随机游走。

加速度计：测比力

fb = Rᵀ(q)·(aworld − gworld) + 噪声　（机体系）

加速度计是「比力」传感器：它测量支撑力产生的等效加速度，等于运动加速度减去重力。 NED 系里重力 g = [0, 0, +9.8]（z 向下）。无人机静止或匀速（悬停微扰近似成立）时 aworld ≈ 0，于是：

fb ≈ −Rᵀ(q)·g　　即「重力方向在机体系的投影」

也就是说：水平放平时加速度计读数 ≈ [0, 0, +9.8]（z 轴朝下所以是正的，与「机体轴 z 下」的约定一致）； 机头抬起 θ，读数变成 [−9.8·sin θ, 0, +9.8·cos θ]——仅由两个分量做 atan2 就能反解出横滚和俯仰 （roll = atan2(fy, fz)，pitch = atan2(−fx, √(fy²+fz²))）。 但机动时 aworld ≠ 0，输出混入运动加速度——加速度计「分不清重力与加速」，这就是它的死穴， 也是「机动线加速度」滑块模拟的现象。另外注意：绕重力轴（偏航）旋转时 fb 完全不变——加速度计天生测不出偏航。

磁力计：测磁场方向

mb = Rᵀ(q)·mworld + 硬铁偏移 + 软铁畸变 + 干扰 + 噪声

地磁场在世界系近似为常向量。本装置设定磁倾角 49°（中国中纬度典型值），即 mworld = B·[cos δ, 0, sin δ]（B ≈ 50 μT，水平分量指北、垂直分量向下）。 磁力计给出第二个不共线的参考方向：重力管「哪边是下」，磁场管「哪边是北」——两个方向联合起来唯一确定姿态。 干扰项是真实工程痛点：机架硬铁（常值偏移）与电机通电磁场（随油门交变）会歪曲 mb， 对应「磁干扰强度」滑块；水平分量被污染的直接后果是偏航被拉偏。

小结　陀螺仪：快、全轴、但积分必漂　｜　加速度计：定横滚俯仰、机动失效、不管偏航　｜　磁力计：定偏航、怕电磁干扰

陀螺仪积分方程：q̇ = ½ q ⊗ ω 的完整推导

这是整条流水线的「预测」引擎。先把问题说成大白话：我知道「这一瞬间我在往哪个方向转、转多快」， 该怎么更新「我的姿势」？推导分四步，每步后面附一句白话。

第一步：微小旋转的四元数

设 t 时刻姿态为 q(t)。之后 dt 内，机体以角速度 ω（机体系表示）转了一小格：绕轴 n̂ = ω/‖ω‖ 转了 dθ = ‖ω‖·dt。由轴角公式，这个小旋转的四元数是：

dq = [cos(dθ/2),　n̂·sin(dθ/2)]　≈　[1,　n̂·dθ/2]　=　[1,　ω·dt/2]　（cos x ≈ 1, sin x ≈ x）

白话：转得非常少的时候，「旋转四元数」退化成「1 + 转轴方向 × 半个转角」。系数 ½ 在这里就出现了——它来自四元数的半角表示，不是人为凑的。

第二步：左乘还是右乘

新姿态 = 旧姿态 ∘ 小旋转。复合用四元数乘法，但乘法不可交换，放左边还是右边有本质区别： 世界系表示的增量旋转左乘，机体系表示的增量旋转右乘。 陀螺仪装在机体上，输出天然是机体系角速度，所以是右乘：

q(t + dt) = q(t) ⊗ dq　=　q(t) ⊗ [1, ω·dt/2]

白话：右乘的增量活在「被 q 转过的坐标系」里——正是机体自己的坐标系。 想象你先朝北再右转 90°，和先右转 90° 再朝北，走出的方向完全不同：旋转与顺序有关，乘法次序就编码了这件事。 （若拿到的是世界系角速度，则改用左乘 q̇ = ½ (0, ωworld) ⊗ q。）

第三步：取导数极限

q̇(t) = limdt→0 [q(t+dt) − q(t)] / dt = q(t) ⊗ [0, ω/2]　⇒　q̇ = ½ · q ⊗ (0, ω)

白话：把「新姿态 − 旧姿态」除以时间就是变化率；实部相乘得 0（[1,·] 的实部 1 减去后归零），推导完毕。

这个方程说明：姿态四元数的运动完全由机体系角速度驱动，且是线性微分方程—— 没有三角函数、没有奇点，任意姿态下同样成立。对比欧拉角速率方程 φ̇ = p + q·sinφ·tanθ + r·cosφ·tanθ …：在 θ=90° 处直接发散，这就是数学层面的万向节锁。

第四步：离散化——代码里每 2 ms 做什么

500 Hz 解算把连续方程变成每帧一步。两种常用离散化：

一阶（快）　q ← q ⊗ [1, ω·dt/2]，然后归一化 精确（本装置用）　Δq = [cos(‖ω‖·dt/2),　(ω/‖ω‖)·sin(‖ω‖·dt/2)]，q ← q ⊗ Δq

白话：「精确」式其实就是轴角公式本身——把一帧内的角增量 ‖ω‖·dt 当作完整旋转处理，大角速度下也不失真。 最后归一化 q ← q/‖q‖ 修掉浮点累积的模长漂移，四元数数值稳定的全部维护成本就这一步。

漂移从哪里进来

把测量模型代入：积分器实际拿到的是 ωg = ωtrue + b + n，于是：

dθ误差/dt = ‖b‖　（零偏 → 姿态角线性漂移）　；　噪声 n → 随机游走（方差随时间线性增长）

零偏 1 °/s 跑 60 秒就是 60° 的偏差——「横滚 360°」剧本里红线飞走的原因。 预测一步无法自救，必须引入不漂的观测来持续纠偏：进入下一节「误差与修正」。

误差的定义：两个「下」方向的叉积

修正的前提是先量化「姿态错了多少、往哪个方向错」。全靠一个优雅的构造——叉积。

两个重力方向

同一个物理向量「重力」，可以由两条独立途径得到它在机体系的表示：

预测　ĝb = Rᵀ(q̂)·gworld　　——拿当前估计姿态把世界系重力旋进机体系（代码 qRotInv） 实测　ab ≈ −Rᵀ(qtrue)·gworld　——加速度计直接测出（静止/匀速时）

白话：ĝb 是「我以为的下」，ab 是「实际测到的下」。 若姿态估计完全正确，两者严格重合；姿态有偏差，两个箭头就岔开一个角度 θerr。 玻璃盒的白箭头（预测 ĝ）与品红箭头（实测 a）展示的正是这两个向量。

叉积为什么能编码旋转误差

e = ab × ĝb　　‖e‖ = ‖a‖‖ĝ‖·sin θerr　≈　θerr（小角度时）

三个性质凑成一个近乎完美的误差信号：

  • 方向——右手定则给出的叉积方向，恰好是「把 ĝb 拧到 ab 所需的旋转轴」。白话：像拧螺丝，叉积告诉你该往哪边拧。
  • 大小——sin θerr 在小角度下 ≈ θerr，误差角越大修正越强（天然的 P 控制器）。
  • 零点——两向量重合时 e = 0，正负号自动指示转过头还是没转够。

也就是说，e 是一个「机体系下的姿态误差角速度」：把它叠加进陀螺角速度， 积分出来的效果就是把姿态往观测方向拉——修正与预测共用同一条积分通道，这是四元数框架最漂亮的地方。

什么时候这个误差不可信

推导假设「ab ∥ 重力」。机动时 ab = 重力 + 运动加速度，方向被拉偏，e 就是错的。 检测手段很简单：‖ab‖ 应恒等于 g = 9.8，明显偏离即受扰（本装置的加速度幅度门控 + 面板红色提示）。 受扰时降低修正权重甚至暂停修正，让陀螺仪独挑——「剧烈机动」剧本下误差曲线先抬头后快速回落， 正是「机动中靠预测、机动后靠观测追回」的完整过程。

修正律：从互补滤波到卡尔曼

有了误差信号 e，最后一步是「拿 e 怎么办」。四种算法给出了四种回答， 本节给直觉与核心公式；每种算法的完整讲解（含调参与适用场景）见文档另一模块「滤波算法讲解」。

互补滤波：欧拉角域的加权平均（暖身）

最朴素的融合在欧拉角域直接混合两条信息：

φ̂ ← φ̂ + (ωx + α·(φacc − φ̂))·dt　（俯仰同构）

白话：陀螺仪积分提供高频细节，加速度计反解角 φacc 提供低频锚点，α 决定「每秒拉近多少」。 滑块「互补 α」调的就是它。缺点：工作在欧拉角域（继承奇点）、无积分项（消不掉零偏）。

Mahony：把误差注入陀螺仪通道

Mahony 把上面的思想搬到四元数域，并把修正量定义为「额外的角速度」：

e = ab × ĝb　　　　　　　　　　　（重力对齐误差） ωused = ωg − (Kp·e + Ki·∫e dt)　　（注入修正后的等效角速度） q̇ = ½ q ⊗ (0, ωused)　　　　　（照常积分）

白话：Kp 像弹簧刚度——偏得越多拉得越快；Ki 像一个慢慢学习的学生——它盯着「总是差的那一点」， 把原因（陀螺仪零偏）记在账上并持续补偿。Ki 的自动消零偏机制：稳态时若陀螺仪有恒定零偏 b， 姿态会维持一个恒定小偏差；积分项持续累积这个误差，直到最后整个修正由 I 项独自承担、 P 项归零、姿态误差也归零——积分器自己「学会」了零偏的补偿值。 面板「P-I 占比条」在带零偏稳态运行时 I 份额上升，演示的正是这个过程；把 Ki 调 0，误差会停在一个不为零的小稳态。

Madgwick：优化视角的梯度下降

Madgwick 换一种哲学：姿态估计是一个最优化问题——找一个 q，使「预测重力」与「实测重力」最接近：

f(q) = ‖ q* ⊗ (0, ĝworld) ⊗ q − (0, ab) ‖²　　（目标函数：预测 vs 实测的残差平方）

f(q) 越小姿态越对。对 f 求关于 q 的梯度，每步沿负梯度走固定步长 β：

q̇ = q̇gyro − β · ∇f(q) / ‖∇f(q)‖　　（陀螺仪预测 + 一步下降）

白话：像蒙着眼下山——感受脚下哪边更陡（梯度），朝下坡方向迈一小步（步长 β）。 β 一个参数同时承担 Mahony 中 Kp 的角色。与 Mahony 的实际差别：无积分项（恒定零偏留下小稳态误差）、 计算量更小、参数更少。本装置用解析梯度，并让磁修正作为独立的偏航方向分量并入， 避免大倾斜时两种梯度相互抵消。

卡尔曼滤波：按「方差」最优加权

前三种的修正增益都是固定的（Kp/β/α 是常数）。卡尔曼滤波多问了一句： 「此刻我更该信谁？」它同时维护预测的不确定度（方差 P，由过程噪声 Q 驱动）与 观测的不确定度（观测噪声 R），按两者之比计算最优增益：

K = P·Hᵀ·(H·P·Hᵀ + R)⁻¹　　K 大 → 多信观测；K 小 → 多信预测

机动中预测方差大、且加速度计受扰被门控 → 自动偏信陀螺仪；静止时观测准 → 自动偏信加速度计。 本装置实现的是飞控标准的误差状态卡尔曼滤波（ES-EKF/MEKF）：协方差维护在 6 维误差状态 [姿态小角误差 δθ, 陀螺仪零偏误差 δb] 上——它还能顺带估计出零偏（面板可见）， 这是前三种算法（除 Mahony 的 I 项外）做不到的。逐步推导见「滤波算法讲解」模块。

磁力计与 MARG：补上偏航这一块

上一节的修正律有个盲区：e = a × ĝ 里，绕重力轴旋转的两个向量都不动——加速度计误差对偏航严格不敏感。 于是纯 IMU 的偏航完全由陀螺仪积分决定，零偏一来就漂（勾掉「启用磁力计」可现场验证）。 磁力计补上缺失的第二个参照向量：重力定义「下」，磁场水平分量定义「北」，两个不共线方向唯一固定姿态的三个自由度。

倾斜补偿航向

磁读数 mb 在机体系里，要先去掉横滚俯仰的影响才能问「北在哪」。设加速度计已给出 φ、θ，标准公式：

mx' = mx·cos θ + my·sin φ·sin θ + mz·cos φ·sin θ my' = my·cos φ − mz·sin φ ψmag = atan2(−my', mx')

几何意义：把磁向量先「摆平」到水平面，再取其在水平面内的方位角。 本装置互补滤波的 MARG 模式就用这个 ψmag 替换陀螺仪偏航（低频锚点）。

MARG 在两种融合律里的形态

Mahony：与重力完全对称。用估计姿态把世界磁场旋进机体系得预测 m̂b = Rᵀ(q̂)·mworld， 磁误差 em = mb × m̂b，其 z 分量并入总误差的偏航通道——重力误差管横滚俯仰，磁误差管偏航，各司其职。 Madgwick：磁修正作为独立的「绕机体系 z 轴」方向分量与重力梯度并列（本装置实现）， 避免大倾斜时两种梯度相互抵消。互补：直接用 ψmag 替换偏航积分值。

干扰的数学后果：硬铁偏移给 mb 加一个常向量 → 水平分量方向恒偏 → 偏航被拉到一个稳定错误值（「磁干扰强度」滑块 + MARG 开启时的现象）； 电机交变场则让偏航抖动。真实飞控的上电校准（转圈拟合硬铁球）与自适应估计就是在解这个问题。 另注意磁北 ≠ 真北：磁偏角（declination）需要查表补偿，本装置未模拟。

Slerp：球面线性插值的推导

姿态估计解决「现在在哪」，插值解决「怎么从 A 平滑走到 B」——相机动画、云台轨迹、关键帧过渡都要它。 「四元数」视图演示的就是这个问题。

理想路径是什么

「匀速走最短路径」在旋转群上的对应物：绕一根固定轴、以恒定角速度从起点转到终点。 机头上任意固定点因此扫出球面的一段大圆弧（球面上两点间的测地线）。四元数视图里的白弧就是它。

公式与推导要点

设单位四元数 q₀、q₁，它们在四维球面上的夹角 Ω 由内积给出：cos Ω = q₀·q₁。Slerp 公式：

slerp(q₀, q₁, t) = [ sin((1−t)Ω)·q₀ + sin(tΩ)·q₁ ] / sin Ω　，　t ∈ [0, 1]

推导思路：待求曲线是四维球面（单位四元数流形）上连接 q₀、q₁ 的一段圆弧， 在 q₀、q₁ 与原点张成的二维平面内参数化——这正是一维「角度插值」在球面上的推广（平面线性插值的球面正弦加权版）。 验证性质：t=0、1 处端点正确；曲线与 q₀ 的夹角随 t 线性增长（恒定角速度）；整条曲线模长恒 1。

短路径处理：双重覆盖的实际代价

q 与 −q 表示同一旋转 ⟹ q₁ 和 −q₁ 都是合法终点。若 cos Ω = q₀·q₁ < 0（两点「隔着半个球」）， 直接插值会走超过 180° 的远路；先把 q₁ 翻成 −q1 再插，Ω 减半、路径最短。 这是实现 Slerp 的标准第一步（代码 qSlerp 的短路径分支）。

欧拉插值为什么「扭」

对 (φ, θ, ψ) 三个分量各自线性插值，等价于每一步都按新角度重新合成旋转—— 瞬时旋转轴本身随 t 连续漂移，机头轨迹偏离大圆、角速度先快后慢（三通道转角分布不均）。 单轴旋转时两者退化重合；多轴复合时中点差异可达 50° 以上（预设姿态对「水平 → [140°, 70°, 160°]」实测 51.6°）。 拖动插值进度 t 到 0.5，白球与品红球在球面上的分离度就是两种表示的差距。

一帧之内：完整算法流程

把所有推导串起来，就是 500 Hz 循环里每 2 ms 发生的事：

读入　ω ← 陀螺仪（含零偏+噪声）　a ← 加速度计　m ← 磁力计（MARG 开时） ① 预测　ω_used ← ω + ω_corr（上一帧算出的修正） 　　　　Δq ← [ cos(‖ω_used‖dt/2), (ω_used/‖ω_used‖)·sin(‖ω_used‖dt/2) ] 　　　　q ← q ⊗ Δq ② 门控　‖a‖ 与 9.8 明显不符 → 判定受扰，跳过观测修正（黏滞 1.5 s） ③ 误差　e ← a × Rᵀ(q)·g_world　　　　　　　　（重力：横滚俯仰） 　　　　e_z ← 磁误差 z 分量　　　　　　　　　　（磁场：偏航，MARG 开时） ④ 修正　ω_corr ← Kp·e + Ki·∫e dt　（Mahony） 　　　　或 q̇ ← q̇_gyro − β·∇f/‖∇f‖　（Madgwick） ⑤ 维护　q ← q / ‖q‖　　　　　　　　　　　　　（归一化，全部维护成本） 输出　每 40 ms 记录曲线点；qToEuler 换算欧拉角供显示

每一行都能在装置里找到对应的可见现象：

  • ① 预测 → 切「纯陀螺仪积分」看它独自工作的漂移；
  • ② 门控 → 剧烈机动时玻璃盒的红色「受扰」提示与品红箭头降饱和；
  • ③ 误差 → 玻璃盒两根箭头的夹角与「重力对齐差」读数；
  • ④ 修正 → 面板「修正」三轴读数与 P-I 占比条；
  • ⑤ 归一化 → 读数 chip 里 q 的模长恒为 1。

至此完整链条闭合：传感器测量模型 → 姿态的四元数表示 → 陀螺仪积分预测 → 叉积观测误差 → 反馈修正 → 归一化输出， 外加插值应用（Slerp）与表示缺陷警示（万向节锁）。建议回到四轴姿态视图，用「手动控制」模式拖动滑块， 对照本文逐行观察这套流水线的实时运转。

滤波算法讲解

本模块逐个拆解本装置运行的五种解算算法：核心思想一句话、数据怎么流动、参数怎么调、优缺点与适用场景。 数学推导在「数学原理」模块；这里聚焦工程直觉与选型。

全景：共同框架 互补滤波 Mahony Madgwick 卡尔曼滤波 对比与选型

全景：所有算法共享同一个框架

五种算法（含纯陀螺仪积分）都可以装进同一个「预测—修正」框架：预测用陀螺仪积分推算下一刻姿态； 修正用加速度计/磁力计的绝对方向观测纠正预测。它们的全部区别只在两件事：

  • 在哪个体空间工作——欧拉角（互补）还是四元数（其余全部）；
  • 修正增益怎么定——固定比例（互补 α / Mahony Kp / Madgwick β）还是按方差自适应（卡尔曼）。
预测（人人相同）　q ← q ⊗ Δq(ω·dt) 修正（各显神通）　互补：欧拉角加权　Mahony：P/I 反馈　Madgwick：梯度下降　卡尔曼：方差加权

对照曲线看：纯陀螺仪积分只有预测（红线漂移）；后四者多一条修正通道（蓝/橙/绿/紫），差距全在修正的品质。

互补滤波：最直观的入门方案

核心思想 频域互补

一句话：陀螺仪高通 + 加速度计低通，两路取长补短。参数：互补 α 滑块。

数据流：陀螺仪积分得到姿态角 → 加速度计 atan2 反解出倾角 → 两者差乘 α 折回积分通道。偏航来自陀螺仪（MARG 开时用倾斜补偿磁航向替换）。

调参现象：α 大 → 跟随快但抖；α 小 → 平滑但慢。调到极端值对比 Mahony，能看出欧拉角域实现的局限（±90° 附近误差定义退化）。

优缺点：实现最简单、计算量最小；但工作在欧拉角域（有奇点）、无积分项（零偏留下稳态误差）。适合入门与算力极受限的场合。

Mahony：飞控里最常用的经典方案

核心思想 P/I 反馈

一句话：把「两个『下』方向的叉积」当作姿态误差，像控制系统一样经比例（Kp）+ 积分（Ki）反馈进陀螺仪通道。参数：Mahony Kp / Ki。

数据流：预测重力 ĝ = Rᵀ(q)·ẑ → 误差 e = a × ĝ → ω 修正 = Kp·e + Ki·∫e → 照常四元数积分。MARG：磁误差 z 分量并入约束偏航。

调参现象：Kp 大收敛快、放大噪声；Ki 负责自动学习陀螺仪零偏（调 0 可见稳态残差）。玻璃盒 P-I 占比条直观显示分工。

优缺点：结构简单、有积分通道、工程验证充分（Betaflight/Cleanflight 系飞控的默认核心）；需要整定两个参数，Kp/Ki 相互耦合。

Madgwick：单参数的优化视角

核心思想 梯度下降

一句话：把「姿态估计」写成目标函数 f(q) = ‖预测重力 − 实测重力‖²，每帧沿负梯度走一步，步长 β。参数：Madgwick β。

数据流：陀螺仪积分项 + β·(−∇f/‖∇f‖) 合成四元数导数；磁场修正作为「绕机体 z 轴」的独立方向分量并入。

调参现象：β 与 Mahony 的 Kp 角色相同（大快抖、小慢稳）；论文推荐 ≈0.1。无积分项 → 恒定零偏留下小幅稳态误差（对比 Mahony 可见）。

优缺点：一个参数、计算量最小、姿态域无奇点；但稳态精度略逊于带积分的方案，论文原版数值梯度在大倾斜时与磁梯度竞争（本装置已用解析梯度 + 独立磁分量规避）。

卡尔曼滤波：按不确定度最优加权

核心思想 方差自适应

一句话：不只估计姿态，还估计「估计得有多不准」（协方差 P），用它和观测噪声 R 的比值算出此刻的最优修正强度。参数：卡尔曼 Q（过程噪声）/ R（观测噪声）。

状态：姿态四元数 q + 陀螺仪零偏 b；协方差维护在 6 维误差状态 x = [δθ(3), δb(3)] 上（误差状态卡尔曼滤波 ES-EKF，也叫 MEKF——飞控与航天器的标准做法：用「小角度误差」做线性化，避免对四元数本身做线性代数）。

三个公式（每帧依次执行）：

预测　P ← Φ·P·Φᵀ + Q·dt　　　　　（姿态随陀螺仪积分走，方差随过程噪声长大） 增益　K = P·Hᵀ·(H·P·Hᵀ + R)⁻¹　（预测方差 vs 观测方差的最优加权） 更新　δx = K·(观测 − 预测)　　　（修正姿态小角误差 + 零偏估计；P 随之收缩）

新息（innovation）：观测减预测的差。本装置设 40° 门控——新息角过大判定为野值直接跳过，这对应「机动中不信加速度计」的工程惯例。

调参现象：Q 大 → 多信观测、跟得快但抖；R 大 → 多信预测、平滑但收敛慢。与 Mahony 不同，K 不是常数而是每帧重算——剧烈机动时自动偏向陀螺仪，静止时自动偏向加速度计。零偏估计 |b| 在面板实时可见：有零偏运行时它应收敛到设定值附近。

优缺点：统计最优（高斯噪声假设下）、能估计零偏、天然融合多传感器与置信度；代价是计算量大（矩阵运算）、调参依赖对噪声水平的先验认知、线性化点错误时可能发散（需野值门控兜底）。适合对精度有要求的飞控与组合导航。

怎么选：学习原理从互补 → Mahony 递进；产品飞控用 Mahony 或卡尔曼；算力极紧用 Madgwick； 需要零偏估计与多传感器置信度管理用卡尔曼。所有方案都不是互斥的——很多飞控同时跑两套互为备份。
