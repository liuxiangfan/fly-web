## 1. 执行纪律（不可逾越）

执行模型在任何时候都不得：

1. 擅自抬任何预算上限、放宽有效门槛或改动 90% 规则；
2. 删除现有教学能力、删减测试、延长超时来换取预算通过；
3. 把未接线的模块在 README／文档／界面里宣传为可用能力；
4. 为了让数字过线，把 C/D 代码藏进无预算约束的角落（内联进 HTML、塞进 public/ 静态目录、拆到不计量的文件）；
5. 用「默认不记录 = 功能不存在」的假接线冒充按需加载——用户打开功能时必须真的能用；
6. 跳过优先级顺序：**高优先级方案未按第 2 节的判据正式失败，不得自行进入低优先级方案**；
7. 自行提交、推送、触发 CI、发布。

## 3. P1（首选）：接线＋归因＋一轮减重，不动预算

### 3.1 接线步骤（模型自主）

1. **C-可观性面板**：在用户打开「误差与可观性」分区时才动态 import 并启动遥测采样；默认关闭路径零分配。
2. **C-事件时间轴**：观测边沿从生产 `onSolve`/遥测状态采样，`EventRecorder` 仅在事件面板首次打开后启动；重置／换源走 `reset(runId)`。
3. **D-历史回看**：用户开启「历史回看」才开始向 `ReviewBuffer` 写帧；关闭即停止写入并释放引用。
4. **D-ESKF 解剖**：仅在选中 ESKF、暂停并打开诊断时才挂 `diagnostics` 采集器；默认路径诊断回调为 undefined。
5. 四个面板全部走 lazy chunk；不得进入首屏主包依赖图。
6. 接线完成后跑 `npx tsc --noEmit && npm run check && npm run build && npm run budget` 拿到第一组真实数字。

### 3.2 归因（模型自主）

用带 sourcemap 的独立重建（不动 `dist/`）输出：

| 归因项 | 接线前 | 接线后 | 增量 |
|---|---|---|---|
| 全部 JS gzip | 269.3 | 实测 | 实测 |
| C 可观性（core＋panel） | — | 实测 | 实测 |
| C 事件（recorder＋timeline＋panel） | — | 实测 | 实测 |
| D 回看（buffer＋panel） | — | 实测 | 实测 |
| D ESKF（estimators 诊断＋panel） | — | 实测 | 实测 |
| 主包接线胶水代码 | — | 实测 | 实测 |
| 教学交互 chunk / 总产物 | 112.5 / 1970.2 | 实测 | 实测 |

归因必须能回答：增量里有没有**重复**（深拷贝、格式化、状态标签、转义工具是否已有可共享实现）、有没有**误拖**（诊断类型被值导入而非类型导入、面板被静态 import 进主包）。

### 3.3 一轮减重（模型自主，仅限以下手段，只做一轮）

允许且仅允许：

1. 共享深拷贝／转义／格式化／标签表，消除模块间重复实现；
2. 诊断与类型改用 `import type`，切断误拖入运行时的依赖；
3. 调整 chunk 分组（C/D 面板与既有 teaching chunk 的分合），消除 gzip 字典重复；
4. 删除接线后确认无调用方的导出（先用静态引用与构建验证，不靠猜）。

明确禁止：删测试、删功能、压缩注释以外的语义改动、改 90% 规则、动任何上限数值。

一轮结束后重跑 §3.1 第 6 步的完整命令，记录第二组数字。

### 3.4 P1 失败判据（满足任一即失败，停止并汇报）

- 一轮减重后，`全部 JS gzip > 270.0 KiB` 有效门槛；
- 或 `产物总量 > 1980.0 KiB` 有效门槛；
- 或教学交互 chunk 超过其有效门槛 115.2 KiB（若接线时调整了 chunk 分组，以分组后该项的有效门槛为准）；
- 或继续减重必须触碰 §3.3 禁止清单里的任何一条。

**注意**：P1 失败的概率很高（估算缺口约 15 KiB）。失败不是执行错误，是预期路径；但必须用实测失败，不能用估算失败。

- 预算报警灵敏度永久下降一档，且先例会降低下一次抬线的心理门槛；

## 5. P3（备选）：缩减 C/D 接线范围

> **进入条件：用户看过 P1 失败数据后，不接受 P2 的预算上调。**

可拆分的最小单元（每种的精确体积需接线实测，下列为构成参考）：

| 选项 | 保留 | 放弃（保持未接线资产） | 用户可见差异 |
|---|---|---|---|
| P3a 只接 C | 可观性面板＋事件时间轴 | 历史回看、ESKF 解剖 | 能解释「观测被拒绝了、偏航没约束」，但不能回到历史时刻、不能看 ESKF 内部 |
| P3b 接 D-ESKF，不接历史回看 | ESKF 单步解剖（暂停后单步采集） | 可观性面板、事件时间轴、历史回看 | 能看懂一次滤波更新的内部，但没有分轴误差解释和时间轴 |
| P3c 接历史回看，不接 ESKF | 回看缓冲＋回看视图 | 可观性面板、事件时间轴、ESKF 解剖 | 能回到历史帧看姿态与输入，但没有事件索引和内部解剖 |

构成参考（来自 `.audit-current/cd-estimate/meta.json` 的独立打包测量，raw minified）：可观性面板组约 13.1 KB、事件面板约 5.8 KB、事件记录器组约 9.0 KB；D 部分与接线胶水的 gzip 增量未单独归因，执行时必须实测。

P3 的文案纪律：被放弃的部分在界面与文档中**完全不可见**，不留灰色按钮或「即将推出」占位；模块文件保留为未接线资产并在 PROJECT-STATE 登记。
