## 本轮确认的实质问题

### P1 · 配置档案仍不能完整复现同一配置

1. **磁/加计校准应用状态未恢复**

   `applyArchiveConfig()` 设置了 `magCalState.applied` 与 `accelCalState.applied`，但没有同步 `magcal-apply` 与 `accelcal-apply` 复选框。之后 `updateMagCalUi()` 会把状态重置为未应用。探针实际确认：档案导入后校准读数消失，后续观测回到未校准输入。

   **处理**：统一恢复校准对象、应用标志、对应 checkbox 与 UI；增加「完整磁校准 + 六面校准 → 导出 → 导入 → 比较估计器输入」回归。

2. **磁校准模型下拉未保存到配置**

   `ExperimentConfig` 保存 `MagCalibration.kind/matrix`，但 `magcal-model` 不在 `currentExperimentConfig()`，也不在 `applyArchiveConfig()` 中恢复。用户选择 full 后导入可能回 diag。

   **处理**：配置中保存当前拟合模型与目标场强；UI/档案/runner 共用；恢复后验证 `MagCalibration.kind` 与所选模型一致。

3. **部分其它运行状态不在档案中**

   A/B 的冻结配置、在线分叉的实际状态、手动目标角、原始记录/时间游标均不在档案里。虽然当前文案已限定为「配置复现」，但仍需明确这些字段是否属于配置快照。

   **处理**：配置档案至少补齐 `magcal-model` 和 `ab.mode`；把「当前运行状态/分叉状态/历史」另列为运行快照，不与配置档案混淆。

### P1 · 校准后的导出→回放数值不闭环

`exportRawCsv()` 和 `exportCsv(imuOn)` 都导出**原始 IMU**，但 `updateEstimators()` 在重放时对原始输入再次应用磁/加计校准。校准开启时，回放会得到不同的数据与统计。

**处理**：

- 定义两种回放输入：`raw-imu`（需要再次校准）与 `calibrated-imu`（不得重复校准）；
- 默认导出带校准来源元数据；原始导出要么显式禁止回放校准复用，要么提供「回放应用校准」开关；
- 增加开启磁/加计校准后的导出→导入→误差序列比较，验证每帧输入一致。

### P1 · 外部真值回放的「真值波形」仍来自模拟世界

`logRow()` 在外部真值回放中使用 `hasGroundTruth()`，随后用 `world.omega`、`world.q` 计算真值陀螺、重力投影与磁场投影。回放带外部真值时 `hasGroundTruth()` 为 true，但 world 的模拟姿态并不是日志真值；曲线标签写「真值」，数据却是模拟量。

**处理**：模拟模式才绘制模拟真值；外部真值回放应从日志读取真值角速度/比力/磁场，或明确标为「日志真值不可用」而不绘制；不能默认把 world 当真值。

### P1 · runner 与在线界面仍不是同一条完整运行路径

`runner.ts` 没有界面的静止粗对准、A/B、INS、闭环等辅助状态机；其配置克隆与 UI 也可能不一致。因此批量结果不能总等价于界面运行。

**处理**：抽出共享 `SimulationSession`，让 UI/runner 使用同一调度、静止对准、A/B、校准和闭环；用 golden trace 比较同 seed 下 runner/UI 的逐帧姿态与统计。

## P2 · 采样、校准与统计的剩余限制

1. **采样率下的噪声口径**

   增加零阶保持采样率后，并没有同步重算每样本白噪声 σ。若继续把当前值解释为固定噪声密度，噪声幅度与采样率关系不正确。

   **处理**：在传感器侧定义噪声密度（°/s/√Hz、m/s²/√Hz）并在采样时按 fs 换算；或明确 UI 滑块表示每样本 σ 并重新命名，不能两种口径混用。

2. **延迟仍是离散帧近似**

   非整数延迟通过历史帧取旧样本，未做插值或状态传播；三传感器真实时间戳/到达调度仍未独立建模。

   **处理**：每帧保留 sampleTime，区分采样、滤波、打包、算法消费；非整数延迟用插值或状态传播，给出简化/完整模型对照。

3. **NEES 与 NIS 的实际模型不同**

   NIS 使用重力方向分量残差，NEES 用完整姿态相对四元数小角误差。两者不是同一统计对象，不能直接解释为「姿态协方差必然正确」；默认悬停场景还出现 NEESθ≈29、NIS≈4，说明目前 R/P 标定偏乐观或模型有差异。

   **处理**：文档明确二者定义与局限；增加固定真值与固定协方差下的独立数值例，检查 NIS/NEES 的分布、尺度和自由度，而不是仅检查有限值。

4. **稳态窗口不是普适定义**

   末段 40% 不一定已收敛，长剧本可能包含新机动/故障阶段；UI 的「未收敛」也不一定适合正常初值。

   **处理**：稳态窗口按可配置绝对时长或首个收敛点之后的阶段；报告标记全程/暂态/稳态，避免将任意末段视为稳态。

5. **tilt/yaw 通过欧拉角分解有奇点影响**

   万向节锁附近 `qToEuler` 的横滚约定会使 tilt/yaw 指标突变；仅查看这些分量可能误解总姿态行为。

   **处理**：除现有欧拉分解外增加 SO(3) 小角向量、绕重力轴偏航/垂直重力方向的误差分解，并标注奇点邻域。

6. **校准静止判据仍有限**

   平均/最大角速度与模长标准差的三重检查已改善，但不能识别所有动态误差、偏置变化、震动或错误朝向；实际六面采集还会受姿态估计/安装方向影响。

   **处理**：加入静置时长、姿态容差与器件独立约束；增加真实硬件样本验证与校准前后独立姿态验证集。

## P2 · 挑战与实验状态的边界

1. `resetExperimentBaseline()` 会把 `ab-toggle` 复位为默认关闭，因此「带 A/B 的挑战/实验」开始时会关闭 A/B；若用户想比较两组参数，语义不明确。

2. `frozenTuning` 只用于测试/显示快照，实际克隆配置由 `cloneOf()` 生成；两套来源虽然当前一致，长期存在漂移风险。

3. same-start 的 A/B 会重置本轮曲线，用户可能把「比较当前历史」误解为保留历史；online-fork 分叉后的粗对准同步仍要改变历史状态，需明确其不是严格的冻结历史。

**处理**：实验配置中显式声明是否允许 A/B、是否重置；冻结配置以 `frozenTuning` 为唯一来源生成克隆；增加「挑战 + A/B」与「分叉后自动对准」的组合用例。

## 建议后续实施顺序

### 第一批 · 修复实际闭环（优先）

1. 恢复校准应用复选框及 UI 状态，并保存/恢复 `magcal-model`；
2. 明确 raw/calibrated IMU 导出回放语义，禁止重复校准；
3. 外部真值回放不再用 world 生成假「真值」波形；
4. 实验基线明确 A/B 是否关闭，冻结配置统一以 `frozenTuning` 生成；
5. 添加上述组合回归用例。

### 第二批 · 统一运行语义与统计

1. 抽出共享 `SimulationSession`，UI 与 runner 共用静止对准、A/B、校准、闭环与 INS；
2. golden trace 验证同 seed 下 runner/UI 逐帧一致；
3. 稳态按实际收敛阶段/可配置窗口；
4. 用 SO(3) 小角向量补充姿态误差分解，避免欧拉奇点污染指标。

### 第三批 · 真实传感器与校准

1. 传感器独立时间戳、采样率/解算率分离、非整数延迟插值；
2. 噪声密度与采样率换算统一；
3. 校准拟合集/验证集分离，真实硬件断线重连与长时间验证；
4. 校准后独立姿态验证和真机对照。

### 第四批 · 性能与文档维护

1. 有界统计/Worker，避免批量保存全部误差序列；
2. 拆分 `main.ts` 为数据源、仿真调度、图表、校准、文档模块；
3. PROJECT-STATE 改为当前状态 + CHANGELOG，动态计数由脚本/检查生成；
4. 文档事实检查与实际模型/计数同步。
