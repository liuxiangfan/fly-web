## 0. 执行总则

### 0.1 项目定位不能变

本项目是**四元数姿态解算教学演示装置**，核心价值是：

- 同一个物理/数学问题同时有直观演示与数字对照；
- 每条重要结论都能在装置中复现；
- 装置的简化边界必须说清楚。

下一轮不以「算法更多、滑块更多、文档页更多」为目标，而以四件事为目标：

1. 现有教材不再说错；
2. 实验从「参数看起来一样」变成「同一配置、同一随机序列、同一评价口径」；
3. 从「某次 RMSE 小」升级为有种子、窗口、分位数和失败率的证据；
4. 将已经写了「本装置看不到」的重要物理现象补成真正的互动现场。

**不做** UKF/粒子滤波/完整 15/24 态组合导航，**不做**完整六自由度飞行模拟器，**不做**教师视角/学生视角页面，**不为了复杂而替换现有有效实现**。

### 0.2 工单标记

- **[C] 已核实的错误/口径矛盾**：应先修，不属于可选功能。
- **[E] 高价值增强**：需要新实现或新实验。
- **[R] 重构**：为后续工作建立可靠基础，不是为拆文件而拆文件。
- **[D] 文档**：内容、结构或生成管线。
- **[F] 后续可选**：完成主线后再考虑。

工单中的行号用于定位当前代码，后续编辑后允许变化；以锚点、函数名和文件职责为准。

### 0.3 推荐依赖顺序

```text
P0 事实校正
  ↓
P1 版本化实验配置 + 确定性随机 + 无 DOM 运行内核 + 明确 A/B 语义
  ↓
P2 批量评测 + 可生成基准 + 挑战改造
  ↓

  ↓
P4 卡尔曼统计诊断 + 可观性定向实验
  ↓
P5 Wahba / 圆锥 / 混叠 / 校准扩展
  ↓
P6 文档重组与去重
```

- **P0 可独立交付**，不要等 P1。
- P2 必须复用 P1 的运行内核，不能用「把动画调快」冒充批量评测。
- P4 的 NEES 依赖有真值的确定性仿真；NIS 可在真实/回放数据中使用。
- 大型功能与文档事实修正分开提交，便于发现错误来源。

## P0-03 [C] 统一互补滤波 α 的方向，修正文档演示中的同向误导

## P1-02 [R] 确定性随机流：seed、重置、初始姿态全部受控

**现状证据**：`World.gauss` 默认 Math.random 且 reset 不重新播种；`randomInitOffset()` 直接使用 Math.random。

**实现**：

1. `World` 构造函数或 `configure()` 接收 seed；`reset()` 恢复该 seed 对应的初始随机状态。
2. 至少拆分 `sensorNoise` 与 `initialAttitude` 两条随机流；传感器内部需要时再用稳定的「轴/传感器标签」派生子流。
3. 随机初始姿态偏差通过同一配置和随机源生成。
4. 保留 `mulberry32` 或选择已定义、可移植的 PRNG；把算法名称写进配置元数据。
5. 文档小演示的 Math.random 不纳入主实验种子，但可单独改固定 seed，方便教学截图复现。

**验收**：

- 同配置同 seed 两次运行的所有 IMU 样本逐值一致；
- 改变磁噪声不改变同 seed 陀螺样本（有独立子流时）；
- 同 seed 重置后初始姿态完全一致；
- 不同 seed 的结果确实不同；
- 所有既有「参数全零不消耗 RNG」守护继续成立。

## P1-03 [R] 完整实验基线与明确 A/B 语义

**现状证据**：`resetExperimentBaseline()` 只重置部分控件；A/B 克隆未复制全部配置和历史状态。

**实验库基线**：

- 不再手工维护「后来新增的控件」清单；每个实验是 `baseConfig + patch`；
- 装载实验 = 由默认完整配置应用 patch，而不是依赖上次 UI 残留；
- `ExperimentSpec` 增加 `configPatch`、`expectedSignals`、`docAnchor` 等结构化字段；
- 文案中的数值从 P2 的基准结果引用，不在实验数据里再写一份。

**A/B 分为两种模式**：

1. **same-start（默认）**：同一初始状态、相同输入、两组不同参数，从零开始对比；界面文案明确「两组从零起跑」。
2. **online-fork（可选）**：到分叉时刻复制完整状态再改一组参数。完整状态包括：
   - 姿态；
   - Mahony `eInt`、门控历史、启动年龄；
   - 卡尔曼 bias、P；
   - 门控阈值、恢复窗、magMode、rampEnabled 等所有配置。

**不建议**用一个含义不清的「克隆」覆盖两种实验。若 online-fork 暂不做，界面必须明说当前是 same-start，并删除「从历史状态直接分叉」的暗示。

**验收**：参数不变时 A/B 逐帧重合；实验按不同顺序装载结果相同；卡尔曼 bias、P 与 Mahony 积分状态按所选模式正确处理。

# P2 · 让算法结论具有统计依据

## P2-01 [E] 新增 Monte Carlo 批量评测与配对比较

**建议新增**：`src/core/benchmark.ts`、`scripts/benchmark.ts`。

**基本设计**：

- 同一组 seed 分别跑每种算法，形成配对样本；
- 分开启动暂态与稳态窗口；
- 每组记录完整 config、seed 列表、PRNG、时长、采样率、版本；
- 默认可从 `N=30、30 s` 开始，正式文档基准再提高 N；CI 使用小规模快速档，夜间/手动跑完整档。

**每种算法至少输出**：

- 总姿态 RMSE：P50、P95、mean；
- 横滚/俯仰/偏航分别 RMSE；
- 收敛时间分布、未收敛比例；
- 最大误差、末端稳态误差；
- 观测拒绝时间占比；
- 卡尔曼 bias 估计误差；
- 数值失败/非法姿态次数。

**比较方式**：

- 输出同 seed 的算法差值，而不只比较两个独立均值；
- 可以附 bootstrap 区间，但不把区间包装成超出仿真模型的现实保证；
- 真实数据无真值时不计算物理 RMSE 排名。

**验收**：同配置批量报告可逐值复现；窗口和样本量明确；UI 可运行小规模批量并导出汇总。

## P4-01 [E] 将遥测升级为「实际接受/拒绝原因」，不只显示传感器模长可信

## P4-02 [E] 新增 NIS、NEES 与协方差一致性实验

**定义**：

- NIS：`νᵀS⁻¹ν`，检查新息与滤波器宣称的观测不确定度；
- NEES：`eᵀP⁻¹e`，仅在有真值时计算，检查实际估计误差是否与 P 匹配；
- 姿态与零偏分别计算 NEES，避免总量掩盖单一通道。

**展示**：

- 玻璃盒显示当前 NIS、滚动均值、样本数、理论参考区间；
- 批量报告输出 NIS/NEES 分布；
- 场景：Q/R 匹配、Q 过小、R 过小、门控过严、观测污染；
- 强调小样本区间和模型非高斯/非线性条件，不把单帧超阈值当发散证明。

**验收**：线性标量例的统计量与解析结果一致；模拟有真值才显示 NEES；真实/回放无真值时隐藏并解释原因。

## P4-03 [E] 保留固定角门控基线，新增 χ² 马氏门控对照

**实现**：

- 沿用 `S=HPHᵀ+R`，门控为 `νᵀS⁻¹ν < threshold`；
- 阈值、观测维数与卡方口径在 UI/文档明确；
- 支持切换角度/马氏门控，作为实验而不是直接替换默认；
- 比较大初值、持续污染、错误 Q/R 下的接受率、RMSE、NIS；
- 同时处理两观测顺序更新时的状态定义，避免拿更新前/后的 S 混用。

**验收**：已知协方差与零新息必然接受，极端新息拒绝；阈值单调性、批量对照与文档数字一致。

## P4-04 [C/E] 不再用「退化时返回单位阵」掩盖卡尔曼求解失败

**现状**：`mat3Inverse()` 在病态时返回单位阵。

**改法**：

- 返回明确失败结果，或使用适合对称正定系统的稳定求解；
- 失败时跳过该次更新并计数值事件；
- 将 S 的对称性、条件/最小对角信息纳入诊断；
- 保留姿态、零偏和 P 的有限性守护，但「没有 NaN」不再视为充分正确；
- 误差态注入后的 `P←GPGᵀ` 可作为另一对照实验，先验证小角极限与数值性质再考虑默认。

**验收**：人为构造病态 S，不进入假正常更新；长期运行 P 对称、半正定；与普通良性参考实现结果一致。

## P5-02 [E] 圆锥效应与混叠实验

**圆锥实验**：

# 附 B · 实施模型必须遵守的技术红线

1. **不要为了让文档成立而改坏正确代码**。先判断是公式、坐标约定、实现还是表述错。
2. **不要把 Mahony 的「P/I 自动消任意误差」扩大化**。它主要处理能被观测约束的偏差；刻度、失准和不可观偏航仍有边界。
3. **不要把完整 MARG 宣称为总是更优**。保留其在不同污染下的正负结果。
4. **不要将 `P_FLOOR`、Joseph 形式、椭球变小解释为滤波器必然正确**。统计一致性另测。
5. **不要将 Mahony 当真实世界的姿态真值**。真实/回放模式只给算法间参考，外部真值需显式提供。
6. **不要将归一化梯度当成普通线性梯度推导 b/β**。
7. **不要将单条随机轨迹的形状当确定增长律**。
8. **不要以「输出没有 NaN」代替算法正确性**。
9. **不要在求解失败时静默用单位阵或零样本冒充正常数据**。
10. **不要让批量评测复制一套算法实现**；必须复用 runner。
